# 新コアカリ対応係 所見（第10回 バッチ3）

## 第10回テーマ
廃棄物の種類と処理、法制度（廃棄物処理法、マニフェスト制度等）、関連法制度の運用における問題点と対策

## バッチ3の特徴

本バッチ20問は、バッチ1（廃棄物処理法の中核）・バッチ2（化学物質規制法／国際条約）と異なり、**化審法・化管法・GHS／SDS／PRTR の化学物質管理の運用面（F014・F021・F042・F064・F541・F1041・F1093・F1262）／労働安全衛生（F030・F052・F1181）／環境法体系（F136・F164・F165・F189・F204・F1259）／生態毒性・有機塩素農薬（F554・F1141）** に重点が置かれた構成。第10回テーマからは「廃棄物処理」そのものより**周辺領域である化学物質規制・産業保健・環境法**に内容がシフトしており、E-1-1-(7)（産業保健）／E-3-1-(1)〜(5)（化学物質管理）／E-3-2-(1)・(5)（環境法）が交錯する。

**重大論点**：化審法・化管法／GHS／SDSの問題が **8問** あり、現在ほぼすべて `E-3-1-(1)` 化学物質の体内動態と毒性 に振られているが、内容的には **法規問題＝E-3-1-(5)** 管理・使用・廃棄に係る法規 が筋。バッチ2のF542・F058と同じ論点が大量にバッチ3で再発しており、コアカリ係と振り分けルールの摺合せが急務。

## 判定基準（バッチ3用）

1. **新カリ E領域への適合**：
   - 化審法・化管法・GHS／SDS等の**法規・制度を問う**問題 → **E-3-1-(5)** 管理・使用・廃棄・薬物乱用・死因究明に係る法規（**推奨**）／場合により **E-3-2-(5)** 環境保全法規
   - 化学物質の体内動態・毒性・生物濃縮を問う問題 → **E-3-1-(1)** 化学物質の体内動態と毒性
   - 化学物質リスクコミュニケーション → **E-3-1-(8)** 化学物質リスクコミュニケーション（CLAUDE.md ガイドラインに明記）
   - 安全性評価・リスク評価方法論 → **E-3-1-(3)** 化学物質の適正管理・使用・保管・廃棄・安全性評価
   - 環境基本法・大気汚染・土壌汚染・典型7公害 → **E-3-2-(1)** 環境汚染・生活環境悪化による健康・生態系への影響、または **E-3-2-(5)** 環境保全法規
   - 労働安全衛生・産業保健・特殊健康診断・特化則・有機則 → **E-1-1-(7)** 社会的要因による職業病・ストレス関連障害の予防
   - 生態毒性試験（藻類・ミジンコ・魚類） → **E-3-1-(3)** 安全性評価（環境影響評価の方法論として）
2. **2024年改正で強調された動向**：
   - 化管法2023年改正：第一種指定化学物質 **515物質**（旧462物質から大幅拡充）、2023年4月施行
   - 化審法：2009年スクリーニング評価導入、2024年生態毒性評価のさらなる活用
   - REACH：2024年現在も継続的に SVHC（高懸念物質）追加、REACH改正案
   - 土壌汚染対策法：2017年（地下水経由経路の強化）、2019年（自然由来含む拡大）改正
   - PCB特措法：高濃度PCB処理期限 2023年3月（北海道事業地域は2026年3月、西日本事業地域では2027年3月延長）、低濃度PCB 2027年3月期限
   - PFAS関連：水道水質暫定目標値（PFOS+PFOA 50 ng/L、2020年4月）、2023年特設委員会、化管法第一種指定化学物質に追加検討
   - 労働安全衛生法 自律的管理移行：2024年4月リスクアセスメント対象物質拡大（約670物質）→ 2026年4月以降約2,900物質まで拡大予定
   - 特殊健康診断項目の追加：2022年特化則改正、2023年化学物質管理者選任義務化
3. **古い概念・用語**：旧「公害」中心 → 新カリ「環境衛生」「資源循環」「リスクベース管理」「自律的管理」志向への整合
4. **薬剤師実務との関連性**：カネミ油症（PCB暴露事件）、PCB特措法2027年処理期限、化学物質管理者制度、SDS提供の実務、地域薬剤師による化学物質情報の住民への翻訳
