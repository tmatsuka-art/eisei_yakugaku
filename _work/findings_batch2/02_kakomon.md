# 過去問係 所見（batch2）

## 全体総括
batch2の5問は「マイクロプラスチック」1問、「リスク認知／リスコミ」2問（理論＋実践）、「気候変動と健康影響」1問、「ロッテルダム条約（PIC条約）」1問という構成。いずれも新コアカリ E-3 系の重要トピックで、出題テーマ選択自体は妥当。ただし F197（気候変動）は future_questions 全体で**3問の強い重複候補**を抱えており差別化が必須。F1015（ロッテルダム条約）は他の国際条約問題群（F034／F036／F1016／F1085／F1178）と論点が大きく被るため、ロッテルダム単独の切り口で独自性を確保する必要がある。出題形式は5問とも「1つ選べ」だが、国試の理論セクションは「2つ選べ」が主流（過去問36問中24問）なので、F197・F1015あたりは2つ選べに組み替える余地もある。

## F035 — マイクロプラスチック
- 類似過去問: 109141（マイクロプラスチック＝プラスチックゴミの生分解により生じた微小粒子＝誤、を選択肢の1つに含む廃棄物問題）
- 国試との比較: **妥当**
  - 109141の選択肢4はまさに「マイクロプラスチックは生分解で生じる（誤）」を問う形で、本問の選択肢2・5と論点が同じ（難分解性、食物連鎖）。難易度は109141と同等で、薬学コアカリの基礎知識として適切。
  - 「粒径5 mm以下」「一次／二次マイクロプラスチックの区別」「疎水性POPsの吸着」「食物連鎖を介した取り込み」と国試で問われる4本柱を1問に網羅しており、知識整理に有用。
- 重複懸念: **あり**（future_questions内で重複が深刻）
  - F198（粒径1mm誤、一次MP＝マイクロビーズ正、淡水・大気でも検出、生分解されにくい）— ほぼ同論点で1つ選べ
  - F872（粒径5mm以下が正答、生分解されない、生物濃縮ありを論点に）— 同じく1つ選べ
  - F1045（粒径5mm以下＋POPs吸着＝正、淡水・血液・胎盤、マイクロビーズ法規制）— 2つ選べだが論点重複
  - F1194（粒径5mm以下、POPs吸着が正答、一次／二次の定義、海洋限定否定）— 1つ選べで F035 と論点ほぼ同じ
  - **F035・F198・F872・F1045・F1194 の5問はほぼ同じ知識を問うており、過剰**。
- 改善提案:
  - F035 は「食物連鎖を介した生体取込み」を正答にしている点が他4問と若干差別化されているので残す価値はあるが、F198 とは粒径定義（5mm vs 1mm誤）・生分解性・一次MP定義など3論点が完全に被る。**F198 と F035 はどちらか統合または削除**を推奨。
  - 残す場合は、F035 を「マイクロビーズの法規制（米国Microbead-Free Waters Act等）」や「海洋プラスチック憲章（G7）」「2024年プラスチック汚染対策に関する国際条約交渉（INC）」など2024〜2026年の最新動向を絡めると差別化できる。
  - または「2つ選べ」化して、「粒径5mm以下が正、食物連鎖を介した生体取込みが正」のペアにすると109141型に近づく。

## F093 — リスク認知
- 類似過去問: **直接対応する過去問なし**。107022（リスコミ定義／必須）と隣接領域。
  - 過去問36問の中にリスク認知の心理的バイアスを単独で問うものはない。リスク分析の3要素（評価・管理・コミュニケーション）は105017や107022で問われるが、「Slovicの未知性・恐ろしさ」「利用可能性ヒューリスティック」レベルの心理学的内容は未出題。
- 国試との比較: **やや難**
  - 国試の必須・理論問題は「定義」「行政機関」「指標（ADI/TDI/VSD）」など制度・定量論を問う傾向で、本問のような認知心理学的概念（自発的vs非自発的、未知性・恐ろしさ）は深く立ち入らない。
  - ただし新コアカリ E-3-1-(8)「リスクコミュニケーション」では認知バイアスにも触れる方針があり、112回以降の新傾向問題として出題される可能性は十分ある。
- 重複懸念: **あり**（future_questions 内で部分重複）
  - F151（リスク認知の心理的要因／2つ選べ）— 利用可能性ヒューリスティック・制御可能性・未知性をほぼ同じ枠組みで問う。F093 と論点完全に被る。
  - F156（メディア報道と認知の歪み）— 利用可能性ヒューリスティックという用語まで含めて被る。
  - **F093 と F151 は実質同じ問題**。F151は「2つ選べ」、F093は「1つ選べ」という形式差のみ。
- 改善提案:
  - F151 と統合するか、F093 を「Slovic の2因子モデル（未知性・恐ろしさ）」に特化させて、F151 を「ヒューリスティック・コントロール感」など別軸に振り分けると差別化できる。
  - もしくは「2024年紅麹サプリ事案」「コロナワクチンへの過大認知」など具体的事例を文脈として与え、その上で認知バイアスを問う実践寄りの問題にすると国試の新傾向（事例文＋知識）に合致する。

## F100 — リスクコミュニケーション（実践）
- 類似過去問: 105017（リスク評価担当機関）, 107022（リスコミ定義／必須）— ただしいずれも理論／必須で、薬剤師の実地対応を問うものは過去問36問中になし。
- 国試との比較: **妥当**（実践問題としては良い作り）
  - 国試の実践セクションは「薬剤師としての適切な対応」を問う形式が中心で、本問はその典型。111242（学校薬剤師の環境衛生検査）と同じ「現場対応」の問い方で、実践問題として適切。
  - 選択肢1「根拠なく心配ないと即答」、選択肢2「専門外として断る」、選択肢4「抗議行動を勧める」、選択肢5「被害確認まで情報提供不要」がいずれも明確に不適切で、選択肢3（傾聴＋科学的情報提供）が正答であることは比較的容易に分かるが、実践問題は元々消去が容易な作りが多く（111242も同様）、国試レベルとして許容範囲。
- 重複懸念: **あり**（future_questions内で部分重複）
  - F153（PFOS地下水検出の住民説明会で薬剤師として最適な対応）— 同じ実践形式で、不適切選択肢の作り方（断言、専門用語、他地域比較）も近い。F100 と F153 は**実践問題2問でほぼ同じ枠組み**。
  - F154（信頼構築の2つ選べ理論）— 「双方向性」「不確実性の伝え方」など F100 解説の論点を理論で問う。
- 改善提案:
  - F100 と F153 の差別化が必要。F100 は「薬局窓口での一般住民からの相談」、F153 は「行政薬剤師としての住民説明会」と場面設定は違うので、設定をより鮮明にする（F100 は薬局店頭・個別相談に特化、F153 は集団対話・公開の場に特化）と棲み分けが明確になる。
  - 実践問題として深みを出すなら、選択肢3を正答にしつつ、「具体的にどの行政機関（保健所／環境省地方環境事務所／PRTR届出データ参照）に問い合わせるか」を選ばせる二段階構成にすると111242型の連問に近づく。

## F197 — 気候変動と健康影響
- 類似過去問: 該当する直接の過去問なし（気候変動の健康影響は新コアカリで新規明示されたテーマ）。間接的関連として 098020（WHOが直接担当しない＝地球温暖化防止対策、必須）。
- 国試との比較: **妥当**（テーマ選択は新コアカリ E-3-2-(4) に合致）
  - 過去問では気候変動は「温室効果ガス」「国際条約」の文脈で出題されてきたが、**健康影響そのものを単独テーマで問う問題は未出題**。新コアカリで E「健康と環境」が再編されたことを受け、112回以降の新規出題が期待される領域。
  - 選択肢4「海面上昇は浸水リスクのみで健康影響はない」が正解（誤りを選ぶ問題）で、他は全て健康影響の正しい記述。誤答選択肢が明確すぎる作りだが、新傾向テーマとしては妥当な難易度。
- 重複懸念: **深刻にあり**（future_questions 内で3問の強い重複）
  - **F039**（気候変動と健康影響／2つ選べ）— 「マラリア等熱帯感染症の流行地域拡大が正」「パリ協定3℃目標が誤」「SDGs目標3」を論点。F197 の選択肢2と論点完全重複。
  - **F1043**（気候変動と健康影響／2つ選べ）— 「熱中症増加が正」「蚊媒介感染症の分布変化が正」「パリ協定3℃目標が誤」「気候変動適応法」「先進国でも問題」を論点。F197 の選択肢1・2と完全重複。
  - **F1192**（気候変動の健康影響／1つ選べ）— 「節足動物媒介感染症の分布域拡大が正」を中心とし、「熱中症のみではない」「冬季超過死亡」「気候変動と大気汚染の関連」「パリ協定4℃目標が誤」を論点。F197 の選択肢2・5と論点完全重複。
  - **F197・F039・F1043・F1192 の4問は実質同じテーマを別角度から問うだけで、解答に必要な知識はほぼ同一**（熱中症増加・媒介感染症分布拡大・食料／大気汚染への影響・パリ協定の目標値）。
  - 国試では同一テーマで4問はあり得ないので、**3問は統合または削除すべき**。
- 改善提案:
  - **F197 を残す場合**: 他3問との差別化のため、「海面上昇の健康影響（飲料水塩水化、感染症、避難ストレス）」「IPCC AR6 報告書の知見」「Lancet Countdown 指標」など、他問が触れていない深い論点に特化させる。
  - **F039 はパリ協定＋SDGs**、**F1043 は気候変動適応法＋緩和策との対比**、**F1192 は媒介感染症（ヒトスジシマカの北上）＋大気汚染との相互関連**、**F197 は海面上昇と複合健康影響**、というように4問それぞれの軸を分けるか、3問に減らすことを強く推奨。
  - 形式面では、F197 を「2つ選べ」に変えると国試の理論問題標準に合う（過去問36問中24問が2つ選べ）。

## F1015 — ロッテルダム条約（PIC条約）
- 類似過去問: 108137（バーゼル・ストックホルム・ワシントン・ウィーン・ロンドン条約の組合せ／2つ選べ）, 110137（水俣条約・カルタヘナ議定書・ストックホルム条約・ロンドン条約1996議定書・モントリオール議定書）, 099140（廃棄物処理＋ロンドン条約・バーゼル条約）, 106138（地球環境問題と国際取組／画像）, 101134（POPs条約）
- 国試との比較: **妥当**（ただしロッテルダム条約単独は珍しい）
  - 国試の国際条約問題は「条約名と規制対象の組合せ／2つ選べ」が主流で、ロッテルダム条約はその中の選択肢の1つとして登場することが多い（108137、110137等にロッテルダムは含まれず、PIC条約の単独問題は過去問36問中になし）。

- 重複懸念: **あり**（future_questions 内で論点重複）
  - F036（国際条約と規制対象の組合せ／1つ選べ）— 選択肢2に「ロッテルダム条約─海洋への廃棄物投棄の規制」（誤）を含み、ロッテルダム＝PIC手続きの知識を問う。
  - F1016（化学物質管理の国際条約と規制対象／1つ選べ）— 選択肢5「ロッテルダム条約─オゾン層破壊物質」（誤）を含み、正答はバーゼル条約。**F1015 と F1016 は問題の作り（5択全てを別条約で構成）がほぼ同じで、正答が違うだけ**。

## 全体への提言

1. **重複の深刻度**: batch2 の5問のうち、**F197・F1015・F035・F093 の4問が future_questions 内で強い重複を抱える**。特に F197（気候変動）は F039／F1043／F1192 と4問重複、F035（マイクロプラスチック）は F198／F872／F1045／F1194 と5問重複、F093（リスク認知）は F151 と概念重複、F1015 は F1085／F195／F1016 と論点重複。**全体の整理（統合・削除）が batch2 後半の最大の課題**。
2. **形式の偏り**: 5問とも「1つ選べ」。国試の理論問題は「2つ選べ」が主流のため、F197・F1015 あたりは2つ選べに組み替えると国試らしくなる。
3. **新コアカリ対応**: F197（気候変動と健康影響）、F035（マイクロプラスチック）、F093（リスク認知バイアス）は新コアカリ E-3 系で新規明示されたテーマで、112回以降の出題価値は高い。重複を整理した上で残せば良問になる。
4. **F100 は実践問題として優良**: 5問中で唯一の実践セクション。F153 との場面設定の棲み分け（薬局窓口 vs 公開説明会）を明確にすれば、両問とも残す価値あり。
5. **整理の優先順位**:
   - 最優先: F197 の他3問（F039／F1043／F1192）との差別化または統合
   - 次点: F035 の他4問（F198／F872／F1045／F1194）との重複整理
   - 次点: F1015 と F1085／F195／F1016 の整理
   - F093 と F151 は形式差（1つ選べ／2つ選べ）で棲み分け可能なら両方残す案も有り
