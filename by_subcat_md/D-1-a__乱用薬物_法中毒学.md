# D-1-a / 乱用薬物・法中毒学
（11問）

## [F543] 乱用薬物・法中毒学 ／ D-1-a

**問題**：覚醒剤の主成分はどれか。1つ選べ。

  1. モルヒネ
  2. Δ9-THC
◯ 3. メタンフェタミン
  4. コカイン
  5. LSD

**正答**：3

**解説**：
1：誤。モルヒネはあへんに含まれる麻薬である。
2：誤。Δ9-THC（テトラヒドロカンナビノール）は大麻の主要な精神活性成分である。
3：正。覚醒剤の主成分はメタンフェタミンおよびアンフェタミンである。覚醒剤取締法で規制されている。
4：誤。コカインはコカの葉に含まれる麻薬である。
5：誤。LSD（リゼルギン酸ジエチルアミド）は合成幻覚剤で麻薬に分類される。

## [F544] 乱用薬物・法中毒学 ／ D-1-a

**問題**：大麻に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 大麻の主要な精神活性成分はモルヒネである
  2. 大麻には依存性がない
◯ 3. 大麻の主要な精神活性成分はΔ9-THC（テトラヒドロカンナビノール）である
  4. 大麻は日本では規制されていない
  5. CBD（カンナビジオール）はΔ9-THCと同じ精神活性作用をもつ

**正答**：3

**解説**：
1：誤。モルヒネはあへんの成分である。大麻の主要精神活性成分はΔ9-THCである。
2：誤。大麻には精神依存性がある。
3：正。大麻の主要な精神活性成分はΔ9-THC（テトラヒドロカンナビノール）であり、カンナビノイド受容体（CB1、CB2）に作用する。
4：誤。大麻は大麻取締法により規制されている。
5：誤。CBD（カンナビジオール）はΔ9-THCのような精神活性作用をもたない。CBDを有効成分とする医薬品（エピディオレックス）がてんかん治療薬として承認されている。

## [F546] 乱用薬物・法中毒学 ／ D-1-a

**問題**：危険ドラッグに関する記述のうち、正しいのはどれか。1つ選べ。

  1. 危険ドラッグは医薬品として承認されたものである
◯ 2. 指定薬物は医薬品医療機器等法により規制される
  3. 危険ドラッグには健康被害のリスクがない
  4. 危険ドラッグは麻薬取締法のみで規制される
  5. 包括指定制度は導入されていない

**正答**：2

**解説**：
1：誤。危険ドラッグは医薬品として承認されたものではなく、法規制を逃れる目的で化学構造を改変した未承認の薬物等である。
2：正。指定薬物は医薬品医療機器等法（旧薬事法）により規制され、製造・輸入・販売・授与・所持・使用等が禁止されている。
3：誤。危険ドラッグには重篤な健康被害（急性中毒、死亡等）のリスクがある。
4：誤。指定薬物は医薬品医療機器等法で規制される。麻薬取締法のみではない。
5：誤。類似構造の化学物質を一括して規制する包括指定制度が導入されている。

## [F550] 乱用薬物・法中毒学 ／ D-1-a

**問題**：法中毒学に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 毛髪からの薬物分析は急性曝露の評価に最も適している
◯ 2. メタンフェタミンのスクリーニング試験にはシモン反応が用いられる
  3. 死後変化は法中毒学的分析に影響しない
  4. 血液は法中毒学分析における唯一の検体である
  5. シアンの予試験にはマルキス試液が用いられる

**正答**：2

**解説**：
1：誤。毛髪からの薬物分析は長期間の曝露履歴（慢性曝露）の評価に適している。急性曝露の評価には血液や尿が適切である。
2：正。メタンフェタミンのスクリーニング試験にはシモン反応が用いられる。第二級アミンであるメタンフェタミンに特徴的な青色呈色反応を示す。
3：誤。死後変化（死後拡散、死後代謝、死後産生等）は法中毒学的分析の結果解釈に大きく影響する。
4：誤。法中毒学分析では血液のほか、尿、毛髪、臓器、胃内容物など多様な検体が用いられる。
5：誤。シアンの予試験にはシェーンバイン-パーゲンステッヘル法が用いられる。マルキス試液は麻薬・覚醒剤等のスクリーニングに用いられる。

## [F912] 乱用薬物・法中毒学 ／ D-1-a

**問題**：マルキス試液を用いたスクリーニング試験に関する記述のうち、正しいのはどれか。1つ選べ。

◯ 1. マルキス試液は濃硫酸にホルマリンを加えて調製する
  2. モルヒネは赤橙色を呈する
  3. メタンフェタミンは青藍色を呈する
  4. マルキス試液は長期保存が可能である
  5. アンフェタミンはマルキス試液で呈色しない

**正答**：1

**解説**：
1：正。マルキス試液は濃硫酸3 mLにホルマリン2〜3滴を加えたものであり、用時調製する。
2：誤。モルヒネ、コデイン、ヘロインなどアヘンアルカロイド類はマルキス試液で青藍色〜紫色を呈する。
3：誤。メタンフェタミン、アンフェタミン、エフェドリン等のフェニルアルキルアミン類は赤橙色を呈する。青藍色を呈するのはモルヒネ類である（選択肢2・3の色の関係を問うひっかけ）。
4：誤。マルキス試液は用時調製であり、長期保存には適さない。
5：誤。アンフェタミン、メタンフェタミン等の覚醒剤類はマルキス試液で赤橙色を呈する。呈色しないわけではない。

## [F914] 乱用薬物・法中毒学 ／ D-1-a

**問題**：中毒原因物質のスクリーニング試験と検出対象の組合せとして、正しいのはどれか。1つ選べ。

  1. クロモトロプ酸法 ── シアン化物
  2. シェーンバイン-パーゲンステッヘル法 ── メタノール
  3. ニトロベンジルピリジン法 ── バルビツール酸系催眠薬
  4. 銅-ピリジン法 ── 有機リン系殺虫剤
◯ 5. ハイドロサルファイトナトリウムによる反応 ── パラコート

**正答**：5

**解説**：
1：誤。クロモトロプ酸法はメタノールの検出に用いられる。シアン化物にはシェーンバイン-パーゲンステッヘル法やピリジン-ピラゾロン法を用いる。
2：誤。シェーンバイン-パーゲンステッヘル法はシアン化物の検出に用いられる。メタノールにはクロモトロプ酸法を用いる。
3：誤。ニトロベンジルピリジン法はブロムワレリル尿素および有機リン系殺虫剤の検出に用いられる。バルビツール酸系催眠薬には銅-ピリジン法を用いる。
4：誤。銅-ピリジン法はバルビツール酸系催眠薬の検出に用いられる。有機リン系殺虫剤にはニトロベンジルピリジン法やアグリスクリーンチケットを用いる。
5：正。ハイドロサルファイトナトリウムによる反応はパラコートの検出に用いられる。

## [F924] 乱用薬物・法中毒学 ／ D-1-a

**問題**：簡易スクリーニング検査キットに関する記述のうち、正しいのはどれか。1つ選べ。

  1. 偽陽性を示す可能性はない
  2. 中毒原因物質の定量が可能である
◯ 3. 腐敗アミンにより覚醒剤が偽陽性を示すことがある
  4. 対象薬毒物が代謝物に変換されても検出感度は変わらない
  5. トリカブト等の自然毒を含むすべての薬毒物を検出できる

**正答**：3

**解説**：
1：誤。簡易検査キットは偽陽性を示す可能性がある。
2：誤。簡易検査キットには定量性がなく、摂取量の特定（定量）はできない。
3：正。代表的な偽陽性として、腐敗アミンによる覚醒剤陽性があげられる。
4：誤。対象となる薬毒物が代謝物へと変換されると感度が低下することがあるため、解釈には注意が必要である。
5：誤。トリカブトなどの自然毒を含む多くの薬毒物の検出はできない。死因判定を目的とする検査としては不十分である。

## [F932] 乱用薬物・法中毒学 ／ D-1-a

**問題**：スクリーニング試験に用いる試料として、適切でないものはどれか。1つ選べ。

  1. 末梢血液（死後変性が少ない）
  2. 尿（薬物代謝物の検出に適する）
  3. 胃内容物（経口摂取の直接証拠）
  4. 胃洗浄液（救急処置時に採取）
◯ 5. 死後に採取した骨髄（長期保存検体）

**正答**：5

**解説**：
1：誤。血液は生前・死後ともに重要な検体であるが、設問の趣旨は死後検査に特有の検体を問うている。
2：誤。尿も一般的な検体であり、死後検査に特有のものではない。
3：誤。胃内容物は経口摂取の証拠として重要であるが、生前の胃洗浄でも採取される。
4：誤。胃洗浄液は救急処置時の検体であり、死後検査に特有の検体ではない。
5：正。骨髄は死後に採取される検体であり、死後変性の影響を受けにくく、長期間埋葬された遺体からも薬毒物を検出できる点で法中毒学的に重要である。

## [F933] 乱用薬物・法中毒学 ／ D-1-a

**問題**：乱用薬物とそのスクリーニング試験に用いる試薬の組合せとして、正しいのはどれか。1つ選べ。

  1. コカイン ── デュケノア試薬
  2. 大麻 ── チオシアン酸コバルト試薬
  3. モルヒネ ── シモン反応
◯ 4. 大麻 ── デュケノア試薬
  5. コカイン ── マルキス試液

**正答**：4

**解説**：
1：誤。コカインのスクリーニングにはチオシアン酸コバルト試薬による反応を用いる。デュケノア試薬は大麻の検出に用いる。
2：誤。大麻のスクリーニングにはデュケノア試薬による反応を用いる。チオシアン酸コバルト試薬はコカインの検出に用いる。
3：誤。モルヒネのスクリーニングにはマルキス試液を用い、青藍色を呈する。シモン反応はメタンフェタミン等の脂肪族二級アミンの検出に用いる。
4：正。大麻のスクリーニングにはデュケノア試薬による反応を用いる。
5：誤。コカインのスクリーニングにはチオシアン酸コバルト試薬を用いる。マルキス試液ではモルヒネ等が青藍色、覚醒剤等が赤橙色を呈する。

## [F934] 乱用薬物・法中毒学 ／ D-1-a

**問題**：ヒ素のスクリーニング試験に用いる方法として、正しいのはどれか。1つ選べ。

  1. 銅-ピリジン法
  2. インドフェノール法
◯ 3. ラインシュ法
  4. ピリジン-ピラゾロン法
  5. ハイドロサルファイトナトリウムによる反応

**正答**：3

**解説**：
1：誤。銅-ピリジン法はバルビツール酸系催眠薬のスクリーニング試験に用いる。
2：誤。インドフェノール法はアセトアミノフェンのスクリーニング試験に用いる。
3：正。ヒ素のスクリーニング試験にはラインシュ法やパックテスト・ヒ素（簡易検出キット）を用いる。
4：誤。ピリジン-ピラゾロン法はシアンのスクリーニング試験に用いる。
5：誤。ハイドロサルファイトナトリウムによる反応はパラコートのスクリーニング試験に用いる。

## [F939] 乱用薬物・法中毒学 ／ D-1-a

**問題**：ニトロベンジルピリジン法によりスクリーニングできる中毒原因物質として、正しいものを2つ選べ。

  1. パラコート
◯ 2. ブロムワレリル尿素
  3. バルビツール酸系催眠薬
◯ 4. 有機リン系殺虫剤
  5. アセトアミノフェン

**正答**：2、4

**解説**：
1：誤。パラコートのスクリーニングにはハイドロサルファイトナトリウムによる反応を用いる。
2：正。ニトロベンジルピリジン法はブロムワレリル尿素のスクリーニングに用いられる。
3：誤。バルビツール酸系催眠薬のスクリーニングには銅-ピリジン法やドリブンフローを用いる。
4：正。ニトロベンジルピリジン法は有機リン系殺虫剤のスクリーニングにも用いられる。
5：誤。アセトアミノフェンのスクリーニングにはインドフェノール法を用いる。
