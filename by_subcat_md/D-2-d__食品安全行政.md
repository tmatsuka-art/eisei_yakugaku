## [F303] 食品安全行政 ／ D-2-d

**問題**：食品衛生行政における監視・行政措置に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 食品衛生監視員になるためには、薬剤師の資格が必須である。
  2. 食品衛生法に基づく営業許可の取消しは、食品安全委員会が行う。
  3. 食品のリコール（自主回収）を行う場合、届出の義務はない。
  4. 輸入食品の検疫は、都道府県の保健所が行う。
◯ 5. 食品衛生監視員は、都道府県知事等が任命し、営業施設への立入検査権限を有する。

**正答**：5

**解説**：
1：誤。食品衛生監視員の任用資格は、医師、歯科医師、薬剤師、獣医師のほか、大学で所定の科目を修了した者等である。薬剤師の資格は必須ではない。
2：誤。営業許可の取消し等の行政処分は、都道府県知事等が行う。食品安全委員会はリスク評価機関であり、行政処分の権限はない。
3：誤。2021年6月施行の改正食品衛生法により、食品のリコール（自主回収）情報の届出が義務化された。事業者は回収に着手した場合、都道府県知事等に届け出なければならない。
4：誤。輸入食品の監視・検査は、厚生労働省の検疫所に配置された食品衛生監視員（輸入食品監視担当）が行う。都道府県の保健所ではない。
5：正。食品衛生監視員は、都道府県知事、保健所設置市長又は特別区長が任命する。食品衛生法に基づき、営業施設への立入検査、食品の収去（検査用試料の無償収去）等の権限を有する。

## [F342] 食品安全行政 ／ D-2-d

**問題**：日本の食品安全に関するリスク分析体制について、正しいのはどれか。2つ選べ。

◯ 1. 食品安全委員会はリスク評価を担当する独立した機関である。
  2. リスク管理は食品安全委員会が一元的に担当する。
  3. リスク評価とリスク管理は同一機関が行うことが望ましい。
◯ 4. 厚生労働省はリスク管理機関の一つである。
  5. リスクコミュニケーションはリスク評価の完了後にのみ実施される。

**正答**：1、4

**解説**：
1：正。食品安全委員会は内閣府に設置されたリスク評価機関であり、リスク管理機関から独立して科学的評価を行う。
2：誤。リスク管理は厚生労働省、農林水産省、消費者庁等の関係府省庁が担当する。食品安全委員会はリスク評価を担当する。
3：誤。リスク評価とリスク管理は機能的に分離（機能分離）することが国際的に求められている。
4：正。厚生労働省は食品衛生法に基づく基準設定や監視指導等のリスク管理を担当する。
5：誤。リスクコミュニケーションはリスク分析の全過程を通じて実施される。

## [F453] 食品安全行政 ／ D-2-d

**問題**：HACCPに関する記述のうち、正しいのはどれか。1つ選べ。

  1. HACCPは最終製品の検査のみで食品の安全性を確保するシステムである
  2. HACCPでは危害要因分析は行わない
  3. HACCPの導入は任意であり法的義務はない
  4. HACCPは日本独自の食品安全管理システムである
◯ 5. HACCPでは食品の製造工程全体を通じて重要管理点（CCP）を設定し監視する

**正答**：5

**解説**：
1：誤。HACCPは最終製品の検査だけでなく、製造工程全体を管理して食品の安全性を確保するシステムである。
2：誤。HACCPの名称自体がHazard Analysis（危害分析）を含んでおり、危害要因分析は基本的な手順である。
3：誤。わが国では食品衛生法の改正によりHACCPに沿った衛生管理が制度化（義務化）されている。
4：誤。HACCPは米国のNASAが宇宙食の安全性確保のために開発したシステムであり、コーデックス委員会が国際的に推奨している。日本独自ではない。
5：正。HACCP（Hazard Analysis Critical Control Point：危害分析重要管理点）では、食品の製造工程全体で危害要因を分析し、重要管理点（CCP）を設定して継続的に監視・記録するシステムである。

## [F455] 食品安全行政 ／ D-2-d

**問題**：食物アレルギーの表示に関する記述のうち、正しいのはどれか。1つ選べ。

◯ 1. 特定原材料として表示が義務付けられている品目にはえび・かにが含まれる
  2. 小麦は表示が推奨されているが義務ではない
  3. 食物アレルギーの表示義務がある特定原材料は28品目である
  4. 大豆は特定原材料として表示が義務付けられている
  5. アレルギー表示は加工食品には適用されない

**正答**：1

**解説**：
1：正。えび・かには特定原材料として表示が義務付けられている8品目に含まれる。
2：誤。小麦は特定原材料として表示が義務付けられている8品目の一つである。
3：誤。表示が義務付けられている特定原材料は8品目（えび、かに、くるみ、小麦、そば、卵、乳、落花生）である。28品目は特定原材料に準ずるもの（表示推奨）を合わせた数に近い。
4：誤。大豆は特定原材料に準ずるもの（表示推奨）であり、表示が義務付けられている特定原材料ではない。
5：誤。アレルギー表示は加工食品に適用される。

## [F775] 食品安全行政 ／ D-2-d

**問題**：食品表示法で定める特定原材料（表示義務あり）に含まれないのはどれか。1つ選べ。

  1. 卵
  2. 乳
  3. そば
◯ 4. 大豆
  5. 落花生

**正答**：4

**解説**：
1：含まれる。卵は特定原材料8品目の一つであり表示義務がある。鶏卵アレルギーは即時型食物アレルギーの原因として最多。
2：含まれる。乳は特定原材料8品目の一つであり表示義務がある。
3：含まれる。そばは特定原材料8品目の一つであり表示義務がある。アナフィラキシーショックを起こしやすい。
4：正（含まれない）。大豆は「特定原材料に準ずるもの」（表示推奨21品目）であり、表示は推奨されているが義務ではない。特定原材料（表示義務）8品目はえび・かに・小麦・そば・卵・乳・落花生・くるみ。
5：含まれる。落花生（ピーナッツ）は特定原材料8品目の一つであり表示義務がある。

## [F792] 食品安全行政 ／ D-2-d

**問題**：HACCPの正式名称に含まれる「CCP」の意味はどれか。1つ選べ。

  1. Chemical Control Point
  2. Central Collection Point
  3. Clinical Care Protocol
  4. Certified Compliance Program
◯ 5. Critical Control Point

**正答**：5

**解説**：
1：誤。Chemical Control Pointではない。
2：誤。Central Collection Pointではない。
3：誤。Clinical Care Protocolではない。
4：誤。Certified Compliance Programではない。
5：正。CCPはCritical Control Point（重要管理点）の略。HACCPはHazard Analysis and Critical Control Point（危害要因分析重要管理点）の略称。

## [F1170] 食品安全行政 ／ D-2-d

**問題**：食品の安全確保に関する国内法規の体系について、正しいのはどれか。2つ選べ。

◯ 1. 食品安全基本法は、食品の安全性確保に関する基本理念と関係者の責務を定めた法律である。
◯ 2. 食品衛生法は、飲食に起因する危害の発生防止を目的とし、食品の規格基準や添加物の規制等を定めている。
  3. 食品表示法は、食品衛生法とJAS法の表示規定のみを統合したものであり、健康増進法の規定は含まれない。
  4. 食品安全委員会は、厚生労働省の内部組織として設置されている。
  5. 食品衛生法に基づく食品の監視・指導は、農林水産省が行う。

**正答**：1、2

**解説**：
食品安全に関する法規体系の全体像を理解することは、衛生薬学の基本です。
1:正　食品安全基本法は食品の安全性確保に関する基本理念と関係者の責務を定めた法律です。
2:正　食品衛生法は飲食に起因する危害の発生防止を目的とした法律です。
3:誤　食品表示法は、食品衛生法、JAS法（農林物資の規格化等に関する法律）、健康増進法の3法の食品表示に関する規定を一元化した法律です。健康増進法の規定も含まれています。
4:誤　食品安全委員会は内閣府に設置されたリスク評価機関であり、厚生労働省の内部組織ではありません。
5:誤　食品衛生法に基づく監視・指導は厚生労働省と都道府県等が行い、農林水産省ではありません。
