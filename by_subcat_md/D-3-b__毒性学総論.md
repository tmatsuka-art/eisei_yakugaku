## [F004] 毒性学総論 ／ D-3-b

**問題**：ある食品添加物について、ラットを用いた2年間の慢性毒性試験で無毒性量（NOAEL）が50 mg/kg/dayと求められた。この食品添加物の一日摂取許容量（ADI）として最も適切なのはどれか。1つ選べ。ただし、安全係数（不確実係数）は100とする。

  1. 0.05 mg/kg/day
  2. 0.1 mg/kg/day
◯ 3. 0.5 mg/kg/day
  4. 5 mg/kg/day
  5. 50 mg/kg/day

**正答**：3

**解説**：
1：誤。0.05 mg/kg/dayは安全係数を1000とした場合の値である。
2：誤。0.1 mg/kg/dayは安全係数を500とした場合の値である。
3：正。ADI = NOAEL / 安全係数 = 50 / 100 = 0.5 mg/kg/day。安全係数100は、種差（10）×個体差（10）の積として設定される。
4：誤。5 mg/kg/dayは安全係数を10とした場合の値である。
5：誤。50 mg/kg/dayはNOAELそのものであり、安全係数を適用していない値である。

## [F007] 毒性学総論 ／ D-3-b

**問題**：化学物質のリスク評価における不確実係数（安全係数）に関する記述のうち、正しいのはどれか。2つ選べ。

  1. 通常、種差に対する不確実係数は100が用いられる
◯ 2. NOAELの代わりにLOAELを用いる場合、追加の不確実係数が適用される
  3. 不確実係数は動物実験のデータをそのままヒトに適用するために用いられる
◯ 4. 通常、種差と個体差を考慮した不確実係数として100（10×10）が用いられる
  5. 耐容一日摂取量（TDI）の算出には不確実係数を用いないのが原則である

**正答**：2、4

**解説**：
1：誤。種差に対する不確実係数は通常10である。100ではない。100は種差（10）×個体差（10）の積である。
2：正。NOAELが求められずLOAELを用いる場合、LOAELからNOAELへの外挿のために追加の不確実係数（通常10）が適用される。
3：誤。不確実係数は、動物実験のデータをヒトに外挿する際に安全域を確保するために用いられるものであり、「そのまま適用する」ためではない。
4：正。通常の不確実係数100は、種差（動物からヒトへの外挿）の10と、ヒトにおける個体差の10を掛け合わせたもの（10×10=100）である。
5：誤。TDIもADIと同様に、NOAEL/不確実係数 で算出される。TDIは意図的に使用されない汚染物質に対して用い、ADIは食品添加物等に対して用いる。

## [F010] 毒性学総論 ／ D-3-b

**問題**：下図は、化学物質AおよびBの用量反応曲線を示す。これらの曲線の解釈として正しいのはどれか。2つ選べ。

  1. 曲線Aは閾値のない直線モデルを示しており、遺伝毒性発がん物質の用量反応に該当する
◯ 2. 曲線Bは閾値のない直線モデルを示しており、遺伝毒性発がん物質の用量反応に該当する
  3. 曲線Aに該当する化学物質にはADI（一日摂取許容量）を設定できない
◯ 4. 曲線Aに該当する化学物質のリスク評価にはNOAELを用いることができる
  5. 曲線Bに該当する化学物質には実質安全量（VSD）の概念は適用されない

**正答**：2、4

**解説**：
1：誤。曲線Aは閾値（約20 mg/kg/day付近）を持つS字型（シグモイド型）曲線であり、非遺伝毒性物質（一般毒性物質）の用量反応パターンに該当する。
2：正。曲線Bは原点を通る直線モデル（閾値なしの直線モデル）を示しており、遺伝毒性発がん物質の用量反応パターンに該当する。低用量でもリスクがゼロにならないことを意味する。
3：誤。曲線Aは閾値のあるモデルであるため、NOAELを求めてADIを設定することができる。ADIを設定できないのは曲線B（閾値なし）に該当する化学物質である。
4：正。曲線Aは閾値のあるモデルであり、毒性が認められない最大用量（NOAEL）を設定することができる。NOAELを不確実係数で除してADIやTDIを算出する。
5：誤。曲線Bに該当する遺伝毒性発がん物質には閾値がないため、ADIは設定できないが、実質安全量（VSD: Virtually Safe Dose）の概念を適用して、生涯リスクが10^{-5}〜10^{-6}以下となる用量を設定することがある。

## [F017] 毒性学総論 ／ D-3-b

**問題**：ダイオキシン類に関する記述のうち、正しいのはどれか。2つ選べ。

  1. ダイオキシン類とは、ポリ塩化ジベンゾ-パラ-ジオキシン（PCDD）のみを指す
  2. 2,3,7,8-TCDDの毒性発現にはアリール炭化水素受容体（AhR）は関与しない
  3. ダイオキシン類の毒性等価係数（TEF）は、すべての異性体で同一の値が設定されている
◯ 4. ダイオキシン類の耐容一日摂取量（TDI）は4 pg-TEQ/kg/dayと設定されている
◯ 5. ダイオキシン類は脂溶性が高く、主に食品（特に魚介類）を介してヒトに摂取される

**正答**：4、5

**解説**：
1：誤。ダイオキシン類対策特別措置法では、ダイオキシン類としてPCDD（ポリ塩化ジベンゾ-パラ-ジオキシン）、PCDF（ポリ塩化ジベンゾフラン）、コプラナーPCB（Co-PCB）の3群を規定している。PCDDのみではない。
2：誤。2,3,7,8-TCDD（最も毒性が強い異性体）はアリール炭化水素受容体（AhR）に結合し、CYP1A1等の遺伝子発現を誘導する。AhRを介した作用がダイオキシン類の主要な毒性発現機序である。
3：誤。毒性等価係数（TEF）は各異性体の毒性の強さを2,3,7,8-TCDDを1として相対的に表した値であり、異性体ごとに異なる。例えば2,3,7,8-TCDD=1、1,2,3,7,8-PeCDD=1、2,3,4,7,8-PeCDF=0.3等と異なる値が設定されている。
4：正。わが国ではダイオキシン類の耐容一日摂取量（TDI）は4 pg-TEQ/kg体重/dayと設定されている。
5：正。ダイオキシン類は脂溶性が極めて高く、環境中で分解されにくいため食物連鎖により生物濃縮される。ヒトへの摂取は食品（特に魚介類、肉、乳製品）経由が約90%以上を占める。

## [F027] 毒性学総論 ／ D-3-b

**問題**：化学物質のリスク評価に関する記述のうち、正しいのはどれか。2つ選べ。

◯ 1. リスクは「有害性（ハザード）×暴露量」で評価される
◯ 2. リスク評価では、有害性の特定（ハザードの同定）が最初のステップである
  3. リスク管理とリスク評価は同一の過程である
  4. リスクコミュニケーションはリスク分析の構成要素に含まれない
  5. 暴露評価では、暴露経路や暴露時間は考慮しない

**正答**：1、2

**解説**：
1：正。リスクは「有害性（ハザード）×暴露量（暴露評価）」で評価される。有害性が高くても暴露がなければリスクは低く、有害性が低くても暴露が大きければリスクは高くなる。
2：正。リスク評価のプロセスは、(1)有害性の特定（ハザードの同定）→(2)用量反応評価→(3)暴露評価→(4)リスクの判定の4ステップで行われる。
3：誤。リスク管理とリスク評価は異なる過程である。リスク評価は科学的・客観的な評価であり、リスク管理は評価結果に基づく行政的・政策的な判断である。
4：誤。リスクコミュニケーションはリスク分析の3つの構成要素（リスク評価、リスク管理、リスクコミュニケーション）の一つである。
5：誤。暴露評価では、暴露経路（経口、吸入、経皮等）、暴露時間（急性、亜急性、慢性）、暴露頻度等を総合的に考慮して評価する。

## [F042] 毒性学総論 ／ D-3-b

**問題**：化学物質の審査及び製造等の規制に関する法律（化審法）に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 化審法は水俣病事件を契機に制定された
◯ 2. 第一種特定化学物質は、難分解性・高蓄積性であり、製造・輸入が原則禁止されている
  3. 新規化学物質は製造開始後に届け出れば足りる
  4. 化審法は食品添加物の安全性審査を主な目的とする法律である
  5. 監視化学物質は第一種特定化学物質と同様に製造・輸入が禁止されている

**正答**：2

**解説**：
1：誤。化審法はカネミ油症事件（1968年、PCB汚染）を契機に1973年に制定された。水俣病事件（メチル水銀中毒）とは異なる。
2：正。第一種特定化学物質は、難分解性・高蓄積性で、人の健康を損なうおそれ又は高次捕食動物に毒性を有する化学物質であり、製造・輸入が原則禁止されている。PCB、DDT等が該当する。
3：誤。化審法では、新規化学物質の製造・輸入に先立ち、事前に届出を行い、国による審査を受けなければならない（事前審査制）。
4：誤。化審法は工業化学物質の安全性評価・規制を目的とする法律である。食品添加物の安全性審査は食品衛生法が担う。
5：誤。監視化学物質は、難分解性であるが高蓄積性の疑いがある段階の物質であり、製造・輸入は禁止されていない。製造・輸入数量の届出や有害性調査の指示等の規制が適用される。

  2. 耐容一日摂取量（TDI）は1 pg-TEQ/kg体重/日と設定されている

## [F069] 毒性学総論 ／ D-3-b

**問題**：化学物質のリスク評価に関する記述のうち、正しいのはどれか。2つ選べ。

  1. リスク評価における「ハザード」とは、化学物質への暴露量（ばく露量）のことをいう
◯ 2. リスクはハザード（有害性）と暴露量の両方を考慮して評価される
  3. 不確実係数（安全係数）は通常10が用いられ、種差のみを考慮するものである
  4. 閾値が存在しない遺伝毒性発がん物質には、NOAELに基づくADI設定が最も適切である
◯ 5. BMD（ベンチマークドーズ）法は、用量反応関係の数理モデルから参照用量を推定する方法である

**正答**：2、5

**解説**：
1：誤。「ハザード」とは化学物質が有する固有の有害性・危険性のことをいう。暴露量はハザードとは別の概念であり、リスク＝ハザード×暴露量として評価される。
2：正。リスクは「ハザード（有害性）」と「暴露量」の両方を考慮して評価される。いくら有害性の高い物質であっても暴露量がゼロであればリスクはなく、逆に有害性が低くても大量に暴露されればリスクは高くなる。
3：誤。不確実係数（安全係数）は通常100が用いられ、種差（動物からヒトへの外挿）の10倍と個体差（ヒトの感受性の個人差）の10倍を掛け合わせたものである。10ではなく100であり、種差だけでなく個体差も考慮する。
4：誤。閾値が存在しない遺伝毒性発がん物質では、どんなに低用量でも理論的にリスクがゼロにならないため、NOAELに基づくADI設定は適切ではない。実質安全量（VSD）やMOE（暴露マージン）、BMD法等を用いたリスク評価が行われる。
5：正。BMD（Benchmark Dose：ベンチマークドーズ）法は、用量反応データに数理モデルを当てはめ、バックグラウンドに対して一定の影響（通常5〜10%の反応率増加）をもたらす用量（BMDL：BMDの信頼下限値）を参照用量として推定する方法である。NOAELに代わる客観的な手法として注目されている。

**問題**：リスク分析（リスクアナリシス）の枠組みに関する記述のうち、正しいのはどれか。1つ選べ。

◯ 1. リスク分析は、リスク評価、リスク管理、リスクコミュニケーションの3つの要素からなる
  2. リスク評価とリスク管理は同一の機関が一体的に実施しなければならない
  3. リスクコミュニケーションはリスク分析の構成要素には含まれず、独立した活動である
  4. リスク管理の主な目的はハザードの同定であり、規制措置の決定は含まれない
  5. リスク分析の枠組みは食品安全の分野にのみ適用される概念である

**正答**：1

**解説**：
1：正。Codex委員会（コーデックス）が提唱するリスク分析（リスクアナリシス）の枠組みは、リスク評価（risk assessment：科学的な有害性・暴露の評価）、リスク管理（risk management：規制措置等の決定・実施）、リスクコミュニケーション（risk communication：関係者間の情報交換）の3要素からなる。

5：誤。リスク分析の枠組みは食品安全の分野で発展したが、化学物質全般、環境、医薬品等の幅広い分野で適用されている。

## [F093] 毒性学総論 ／ D-3-b

**問題**：化学物質のリスク認知に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 一般市民のリスク認知は科学的なリスク評価の結果と常に一致する
  2. 自発的に引き受けるリスク（喫煙等）は、非自発的に暴露されるリスク（環境汚染等）よりも大きく認知される傾向がある
  3. メディアで頻繁に報道されるリスクは、実際のリスクよりも過小に認知される傾向がある
◯ 4. 未知性の高いリスクや恐ろしさの大きいリスクは、実際のリスクよりも過大に認知される傾向がある
  5. リスク認知には心理的バイアスが存在しないため、科学的リスク評価のみで十分な合意形成ができる

**正答**：4

**解説**：
1：誤。一般市民のリスク認知は様々な心理的・社会的要因の影響を受けるため、科学的なリスク評価の結果とは必ずしも一致しない。この乖離を理解することがリスクコミュニケーションにおいて重要である。
2：誤。一般に、自発的に引き受けるリスク（喫煙、飲酒等）は小さく認知され、非自発的に暴露されるリスク（環境汚染、食品添加物等）は実際よりも大きく認知される傾向がある。記述は逆である。
3：誤。メディアで頻繁に報道されるリスクは、実際のリスクよりも「過大」に認知される傾向がある（利用可能性ヒューリスティック）。過小ではない。
4：正。Slovic（スロビック）らのリスク認知研究によると、「未知性」（新しい、科学的に不確実な）と「恐ろしさ」（制御不能、致死的、非自発的）の2つの因子がリスクの過大認知に関与する。放射性物質や遺伝子組換え等がこれに該当する。

## [F099] 毒性学総論 ／ D-3-b

**問題**：化学物質のリスク評価における定量的指標に関する記述のうち、正しいのはどれか。1つ選べ。

  1. MOE（暴露マージン）は暴露量をNOAELで除した値であり、値が大きいほどリスクが高い
  2. ADI（一日許容摂取量）を超える摂取があった場合、直ちに健康被害が発生する
  3. VSD（実質安全量）とは、発がんリスクが100%となる用量を意味する
◯ 4. TDI（耐容一日摂取量）は、環境汚染物質など非意図的に暴露される物質に対して設定される
  5. NOAELとLOAELは常に同一の値を示す

**解説**：
1：誤。MOE（Margin of Exposure：暴露マージン）はNOAEL（又はBMDL）を実際の暴露量で除した値（MOE = NOAEL/暴露量）であり、値が大きいほどリスクは低い（安全性が高い）。記述では分子と分母が逆であり、値の解釈も逆である。
2：誤。ADIは安全係数（通常100倍）を考慮して設定されているため、一時的にADIを超える摂取があっても直ちに健康被害が発生するわけではない。ADIは生涯にわたって毎日摂取しても健康への悪影響が認められない量である。

5：誤。NOAEL（No Observed Adverse Effect Level：無毒性量）は有害影響が認められない最大用量であり、LOAEL（Lowest Observed Adverse Effect Level：最小毒性量）は有害影響が認められる最小用量である。LOAEL > NOAELの関係にあり、両者は異なる値である。

## [F1318] 毒性学総論 ／ D-3-b

**問題**：ある食品添加物のADIが0.1 mg/kg体重/日である。体重60 kgの成人がこの添加物を含む食品を1日に300 g摂取する場合、食品中のこの添加物の最大許容濃度に最も近い値はどれか。1つ選べ。

  1. 2 mg/kg食品
  2. 6 mg/kg食品
  3. 10 mg/kg食品
◯ 4. 20 mg/kg食品
  5. 60 mg/kg食品

**正答**：4

**解説**：
ADIから食品中の最大許容濃度を求める応用問題です。
1:誤
2:誤
3:誤
4:正　最大一日摂取量＝ADI×体重＝0.1×60＝6 mg/日。食品摂取量300 g＝0.3 kgなので、最大許容濃度＝6 mg÷0.3 kg＝20 mg/kg食品。
5:誤

## [F1319] 毒性学総論 ／ D-3-b

**問題**：ある食品添加物のADIが0.2 mg/kg体重/日である。体重20 kgの小児がこの添加物を含む食品を1日に200 g摂取している。実際の食品中濃度が15 mg/kgであるとき、ADIに対する摂取割合に最も近い値はどれか。1つ選べ。

  1. 25%
  2. 50%
◯ 3. 75%
  4. 100%
  5. 150%

**正答**：3

**解説**：
ADIに対する摂取割合の計算問題です。小児を対象とした設定です。
1:誤
2:誤
3:正　実際の一日摂取量＝15 mg/kg×0.2 kg＝3.0 mg/日。ADIに基づく最大一日摂取量＝0.2 mg/kg体重/日×20 kg＝4.0 mg/日。摂取割合＝3.0/4.0×100＝75%。ADIの75%に相当する摂取量です。
4:誤
5:誤
