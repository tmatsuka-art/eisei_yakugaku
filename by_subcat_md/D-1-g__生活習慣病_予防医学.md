## [F578] 生活習慣病・予防医学 ／ D-1-g

**問題**：喫煙と健康に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 受動喫煙は健康に影響しない
  2. ニコチンに依存性はない
◯ 3. 喫煙はCOPD（慢性閉塞性肺疾患）の最大のリスク要因である
  4. 健康増進法では受動喫煙対策は規定されていない
  5. 喫煙は心血管疾患のリスクを低下させる

**正答**：3

**解説**：
1：誤。受動喫煙は肺がん、心疾患、COPD等のリスクを高めることが明らかにされている。
2：誤。ニコチンは強い依存性（精神依存・身体依存）をもつ。
3：正。喫煙はCOPDの最大のリスク要因であり、COPD患者の約90%に喫煙歴がある。
4：誤。健康増進法（2018年改正）では受動喫煙対策が強化され、多数の者が利用する施設での原則屋内禁煙等が規定された。
5：誤。喫煙は動脈硬化を促進し、心血管疾患のリスクを高める。

  2. リハビリテーションによる機能回復

## [F1036] 生活習慣病・予防医学 ／ D-1-g

**問題**：ゲノム編集技術に関する記述のうち、正しいのはどれか。1つ選べ。

  1. SDN-1は、外来遺伝子を標的部位に挿入する技術である。
◯ 2. SDN-2は、標的部位を切断し、数塩基の置換や挿入を鋳型DNAを用いて行う技術である。
  3. SDN-3は、標的部位を切断するのみで、外来遺伝子の挿入は行わない技術である。
  4. ZFN（ジンクフィンガーヌクレアーゼ）はRNAをガイドとして用いるゲノム編集技術である。
  5. TALENは、細菌由来のCRISPR配列を利用したゲノム編集技術である。

**正答**：2

**解説**：
ゲノム編集技術にはSDN-1、SDN-2、SDN-3の3つのカテゴリーがあり、それぞれ規制の取扱いが異なります。
1:誤　SDN-1（Site-Directed Nuclease type 1）は、標的部位を切断するのみで、外来遺伝子の挿入は行いません。切断後のDNA修復過程で生じるランダムな変異（挿入・欠失）を利用します。
2:正　SDN-2（Site-Directed Nuclease type 2）は、標的部位を切断した後、短い鋳型DNAを用いて数塩基の置換や挿入を行う技術です。
3:誤　SDN-3（Site-Directed Nuclease type 3）は、標的部位を切断し、外来遺伝子を含む長いDNA断片を挿入する技術です。SDN-1の説明と入れ替わっています。
4:誤　ZFN（Zinc Finger Nuclease）はタンパク質のジンクフィンガーモチーフによりDNA配列を認識するゲノム編集技術であり、RNAをガイドとして用いるのはCRISPR-Cas系です。
5:誤　TALEN（Transcription Activator-Like Effector Nuclease）は、植物病原菌キサントモナス由来のTALエフェクターを利用した技術であり、CRISPR配列は使用しません。

## [F1038] 生活習慣病・予防医学 ／ D-1-g

**問題**：日本で届出されたゲノム編集技術応用食品・飼料に関する記述のうち、正しいのはどれか。1つ選べ。

  1. GABA高蓄積トマトは、グルタミン酸脱炭酸酵素遺伝子の機能を強化することでGABA含量を増加させたものである。
◯ 2. 可食部増量マダイは、ミオスタチン遺伝子を破壊することで筋肉量を増加させたものである。
  3. 高成長トラフグは、成長ホルモン遺伝子を外部から導入して成長を促進させたものである。
  4. ゲノム編集技術応用食品の届出は農林水産省に対して行う。
  5. 届出されたゲノム編集技術応用食品は、すべて植物由来のものに限られる。

**正答**：2

**解説**：
日本で届出されたゲノム編集技術応用食品の具体例と特徴を理解することが求められます。
1:誤　GABA高蓄積トマトは、グルタミン酸脱炭酸酵素（GAD）の自己阻害ドメインを破壊（機能抑制の解除）することでGABA含量を増加させたものです。遺伝子の「機能を強化」したのではなく、自己阻害機能を除去したものです。
2:正　可食部増量マダイは、筋肉量を抑制するミオスタチン遺伝子をゲノム編集で破壊（ノックアウト）することで、筋肉量を増加させ可食部を増やしたものです。
3:誤　高成長トラフグは、食欲を抑制するレプチン受容体遺伝子をゲノム編集で破壊することで摂食量を増加させたものであり、外部からの成長ホルモン遺伝子の導入は行っていません。
4:誤　ゲノム編集技術応用食品の届出は厚生労働省（食品の場合）に行います。飼料については農林水産省です。
5:誤　可食部増量マダイや高成長トラフグなど、動物由来のゲノム編集技術応用食品も届出されています。

## [F1045] 生活習慣病・予防医学 ／ D-1-g

**問題**：マイクロプラスチックによる環境汚染と健康影響に関する記述のうち、正しいのはどれか。2つ選べ。

◯ 1. マイクロプラスチックとは、一般に粒径5 mm以下の微細なプラスチック粒子のことをいう。
  2. マイクロプラスチックは海洋環境のみで検出されており、淡水域（河川・湖沼）や農地土壌からは検出されていない。
◯ 3. マイクロプラスチックには、環境中の残留性有機汚染物質（POPs）が吸着・濃縮される性質がある。
  4. マイクロプラスチックは海水中の微生物により90日以内に速やかに生分解される。
  5. 洗顔料等に含まれるマイクロビーズ（粒径0.1〜1 mm）の製造・販売は日本では法律で全面的に禁止されている。

**正答**：1、3

**解説**：
マイクロプラスチックによる環境汚染は、新たな環境衛生上の課題として注目されています。
1:正　マイクロプラスチックは、一般に5 mm以下の微細なプラスチック粒子と定義されています。一次マイクロプラスチック（マイクロビーズ等として製造されたもの）と二次マイクロプラスチック（大きなプラスチックが破砕・劣化して生じたもの）があります。
2:誤　マイクロプラスチックは海洋だけでなく、河川・湖沼などの淡水環境、土壌、大気、さらにはヒトの血液や胎盤からも検出が報告されています。
3:正　マイクロプラスチックは疎水性であるため、環境中のPCB、DDT、PAHsなどの残留性有機汚染物質（POPs）を表面に吸着・濃縮する性質があります。これにより、食物連鎖を通じた有害物質の移行が懸念されています。
4:誤　プラスチックは自然環境中での生分解性が極めて低く、数百年以上残存するとされています。紫外線や物理的作用で微細化しますが、完全に分解されるまでには非常に長い時間を要します。
5:誤　日本ではマイクロビーズの使用に関して業界の自主規制は進んでいますが、法律による全面的な製造・販売禁止には至っていません（一部の国では規制法があります）。

◯ 1. 次亜塩素酸ナトリウムは、ノロウイルスに対して有効な消毒薬である。
  2. 消毒用エタノール（約80%）は、芽胞に対しても有効である。
◯ 3. グルタルアルデヒドは、高水準消毒薬に分類され、内視鏡の消毒に使用される。
  4. 逆性石けん（塩化ベンザルコニウム）は、結核菌に対して有効である。
  5. クレゾール石けん液は、ウイルスに対して広く有効な消毒薬である。

**正答**：1、3

**解説**：
消毒薬の種類と適用範囲を正確に理解することは、感染対策の基本です。
1:正　次亜塩素酸ナトリウムは、ノロウイルス（ノンエンベロープウイルス）に対して有効です。嘔吐物の処理には0.1%（1000 ppm）、環境消毒には0.02%（200 ppm）が使用されます。

3:正　グルタルアルデヒドは高水準消毒薬であり、芽胞を含むほとんどの微生物に有効です。内視鏡などの耐熱性のない医療器具の消毒に使用されます。
4:誤　逆性石けん（塩化ベンザルコニウム等）は低水準消毒薬であり、結核菌に対しては無効です。結核菌に有効なのはグルタルアルデヒドや次亜塩素酸ナトリウムなどです。
5:誤　クレゾール石けん液は中水準消毒薬であり、細菌（結核菌を含む）や真菌には有効ですが、ウイルスに対する効果は限定的です。
