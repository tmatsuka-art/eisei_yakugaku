## [F013] 毒性学総論 ／ D-3-a

**問題**：カドミウムによる健康被害に関する記述のうち、正しいのはどれか。2つ選べ。

  1. カドミウムは体内でメタロチオネインと結合せず、遊離型として毒性を発揮する
  2. イタイイタイ病では、カドミウムの直接作用により骨が脆弱化する
  3. カドミウムの生物学的半減期は数日と短く、慢性毒性は生じにくい
◯ 4. カドミウムの慢性暴露により、近位尿細管の再吸収機能が障害される
◯ 5. 尿中β2-ミクログロブリンの増加は、カドミウムによる腎障害の指標となる

**正答**：4、5

**解説**：
1：誤。カドミウムは体内でメタロチオネイン（金属結合タンパク質）と結合する。肝臓で合成されたカドミウム-メタロチオネイン複合体が腎臓の近位尿細管で再吸収され、そこでカドミウムが遊離して毒性を発揮する。
2：誤。イタイイタイ病における骨軟化症は、カドミウムの骨への直接作用ではなく、腎臓の近位尿細管障害によるビタミンD活性化障害（1α-水酸化酵素の障害）およびカルシウム・リンの再吸収障害が原因である。
3：誤。カドミウムの生物学的半減期は10〜30年と非常に長い。このため体内に蓄積し、慢性毒性を引き起こしやすい。
4：正。カドミウムの慢性暴露により、腎臓の近位尿細管の再吸収機能が障害され、低分子タンパク質、糖、アミノ酸、カルシウム、リン等が尿中に排泄される（Fanconi症候群様の症状）。
5：正。尿中β2-ミクログロブリン（低分子タンパク質）の増加は、近位尿細管の再吸収機能障害を反映するカドミウム腎症の早期指標として用いられる。

## [F014] 毒性学総論 ／ D-3-a

**問題**：化学物質の審査及び製造等の規制に関する法律（化審法）およびPRTR制度に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 化審法では、新規化学物質の届出前に安全性審査を行う必要はない
◯ 2. 化審法の第一種特定化学物質は、難分解性、高蓄積性を有し、長期毒性が認められる物質である
  3. PRTR制度は、化学物質の製造を禁止するための制度である
  4. PRTR制度では、対象事業者は化学物質の排出量を届け出る義務はない
  5. 化審法の監視化学物質には、PCBやDDTが指定されている

**正答**：2

**解説**：
1：誤。化審法では、新規化学物質の製造・輸入前に事前審査（安全性審査）が義務づけられている。これが化審法の最大の特徴である。
2：正。第一種特定化学物質は、難分解性、高蓄積性（高濃縮性）を有し、人への長期毒性または高次捕食動物への長期毒性が認められる化学物質である。PCB、DDT、アルドリン等が指定されている。製造・輸入が原則禁止される。
3：誤。PRTR（Pollutant Release and Transfer Register：化学物質排出移動量届出）制度は、化学物質の環境中への排出量・移動量を把握・公表する制度であり、製造を禁止する制度ではない。化管法に基づく。
4：誤。PRTR制度では、対象事業者は第一種指定化学物質の環境中への排出量および事業所外への移動量を国に届け出る義務がある。
5：誤。PCBやDDTは化審法の「第一種特定化学物質」に指定されている。「監視化学物質」は、難分解性かつ高蓄積性であるが、毒性が未確認の物質に対する分類である。

## [F019] 毒性学総論 ／ D-3-a

**問題**：内分泌かく乱化学物質（いわゆる環境ホルモン）に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 内分泌かく乱作用を持つ化学物質は、すべて合成化学物質である
  2. ビスフェノールAは男性ホルモン（アンドロゲン）様作用を示す
◯ 3. トリブチルスズ化合物は、巻貝にインポセックス（雌の雄性化）を引き起こすことが知られている
  4. 内分泌かく乱化学物質は、高濃度でのみ生体影響を及ぼす
  5. ダイオキシン類には内分泌かく乱作用はない

**正答**：3

**解説**：
1：誤。内分泌かく乱作用を持つ物質には、合成化学物質（ビスフェノールA、フタル酸エステル等）だけでなく、植物由来のフィトエストロゲン（大豆イソフラボン等）のような天然物質も含まれる。
2：誤。ビスフェノールAは女性ホルモン（エストロゲン）様作用を示す。エストロゲン受容体に結合して内分泌かく乱作用を発揮する。アンドロゲン様作用ではない。
3：正。トリブチルスズ（TBT）化合物は船底塗料等に使用されていた有機スズ化合物であり、巻貝（イボニシ等）の雌にペニス様構造が形成されるインポセックス（imposex）現象を引き起こすことが知られている。
4：誤。内分泌かく乱化学物質は、極めて低濃度でもホルモン受容体に結合して内分泌系を撹乱する可能性がある。従来の毒性学的な用量反応関係では説明できない低用量効果が指摘されている。
5：誤。ダイオキシン類（特に2,3,7,8-TCDD）はAhRを介して甲状腺ホルモンや性ホルモンの代謝に影響を及ぼし、内分泌かく乱作用を有する。

## [F021] 毒性学総論 ／ D-3-a

**問題**：化学品の分類および表示に関する世界調和システム（GHS）に関する記述のうち、正しいのはどれか。1つ選べ。

  1. GHSは各国独自の化学物質分類制度を維持することを目的としている
  2. GHSの絵表示（ピクトグラム）は青色の正方形の中にシンボルを配置する
◯ 3. GHSでは、化学品の有害性を健康有害性、物理化学的危険性、環境有害性の3つに大別する
  4. GHSに基づく安全データシート（SDS）の記載項目は各国が独自に定める
  5. GHSでは、危険有害性情報（Hステートメント）と注意書き（Pステートメント）は同一のコード体系である

**正答**：3

**解説**：
1：誤。GHSは化学品の分類と表示を世界的に統一・調和することを目的とした国連のシステムである。各国独自の制度を維持するためではない。
2：誤。GHSの絵表示（ピクトグラム）は、赤色の菱形（正方形の45°回転）の中に黒色のシンボルを配置する。青色の正方形ではない。
3：正。GHSでは、化学品の有害性を健康有害性（急性毒性、発がん性、生殖毒性等）、物理化学的危険性（引火性、爆発性、酸化性等）、環境有害性（水生環境有害性等）の3つに大別している。
4：誤。GHSに基づくSDSの記載項目は国際的に統一されており、16項目（化学品の名称、危険有害性の要約、組成情報、応急処置等）が定められている。各国が独自に定めるものではない。
5：誤。Hステートメント（危険有害性情報）とPステートメント（注意書き）はそれぞれ異なるコード体系である。HはHazard（例：H301）、PはPrecaution（例：P301）を示す。

## [F023] 毒性学総論 ／ D-3-a

**問題**：化学物質の毒性試験に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 単回投与毒性試験は、主に標的臓器の特定を目的とする
◯ 2. 反復投与毒性試験は、毒性の用量依存性や標的臓器の特定に有用である
  3. 生殖発生毒性試験では、毒性の可逆性を評価する
  4. 慢性毒性試験では。90日間の反復投与を行う
  5. 遺伝毒性試験は、動物個体への影響を評価するもので、DNAへの影響は含まない

**正答**：2

**解説**：
1：誤。単回投与毒性試験（急性毒性試験）の主な目的は、LD50（概略の致死量）の求め、中毒症状の観察、死亡までの時間経過の把握である。標的臓器の特定は主に反復投与毒性試験の目的である。
2：正。反復投与毒性試験（28日間、90日間等）は、毒性の用量依存性、NOAELの決定、標的臓器の特定、毒性の可逆性の評価に有用である。
3：誤。生殖発生毒性試験は、化学物質の生殖機能（受胎、姊娠、分娩等）や胎児の発生（催奇形性）への影響を評価する試験である。毒性の可逆性の評価は反復投与毒性試験の目的である。
4：誤。慢性毒性試験では、90日間ではなく、通常は被験動物の寿命の大部分（ラットで2年間）にわたる反復投与を行う。90日間の反復投与は亜急性毒性試験に該当する。
5：誤。遺伝毒性試験はDNAや染色体への影響（突然変異、染色体異常、DNA損傷等）を評価する試験である。動物個体への影響だけでなくDNAレベルの評価が中心である。

## [F029] 毒性学総論 ／ D-3-a

**問題**：生殖発生毒性試験に関する記述のうち、正しいのはどれか。2つ選べ。

  1. 催奇形性試験では、雄の生殖機能への影響のみを評価する
  2. 器官形成期に被験物質を投与する場合、親動物のみに投与すれば十分である
◯ 3. セグメントI試験では、交配前から姙娠初期までの投与による受胎能や着床への影響を評価する
  4. セグメントIII試験では、器官形成期の毒性を主に評価する
◯ 5. 生殖発生毒性試験では、次世代への影響も評価対象となる

**正答**：3、5

**解説**：
1：誤。催奇形性試験（セグメントII試験）では、器官形成期に雌の親動物に被験物質を投与し、胎児の形態異常（奇形）を評価する。雄の生殖機能のみの評価ではない。
2：誤。器官形成期の被験物質投与は雌の親動物に行うが、評価は親動物だけでなく胎児の形態異常、発育遅延、死亡等も評価する。「親動物のみに投与すれば十分」という記述は誤解を招くが、投与自体は親動物に行うので、「親動物だけで十分」という表現が誤り。胎児への影響も評価する必要がある。
3：正。セグメントI試験（受胎能及び着床までの試験）では、交配前から姙娠初期までの投与により、受胎能、着床、初期胚発生への影響を評価する。
4：誤。セグメントIII試験（周産期及び授乳期試験）では、姙娠後期から授乳期までの投与による分娩、哺育、新生児の発育への影響を評価する。器官形成期の毒性評価はセグメントII試験である。
5：正。生殖発生毒性試験では、親動物への影響だけでなく、次世代（F1世代）やその次の世代（F2世代）への影響（多世代生殖毒性試験）も評価対象となる。

◯ 2. ホルムアルデヒドは、乳幼児用繊維製品に含まれる有害物質として基準が設定されている

## [F058] 毒性学総論 ／ D-3-a

**問題**：化学物質・薬物とその主な規制法の組合せとして、正しいのはどれか。1つ選べ。

  1. PCB ── 毒物及び劇物取締法
  2. メタンフェタミン ── 大麻取締法
  3. ダイオキシン類 ── 農薬取締法
  4. トリクロロエチレン ── 覚醒剤取締法
◯ 5. モルヒネ ── 麻薬及び向精神薬取締法

**解説**：
1：誤。PCB（ポリ塩化ビフェニル）は化審法で第一種特定化学物質として規制されている。また、PCB廃棄物の適正処理についてはPCB特別措置法が適用される。毒物及び劇物取締法ではない。
2：誤。メタンフェタミンは覚醒剤取締法で覚醒剤として規制されている。大麻取締法ではない。
3：誤。ダイオキシン類はダイオキシン類対策特別措置法で規制されている。農薬取締法ではない。
4：誤。トリクロロエチレンは有機溶剤中毒予防規則や特定化学物質障害予防規則で規制されるほか、化審法の第二種特定化学物質にも指定されている。覚醒剤取締法ではない。
5：正。モルヒネは麻薬及び向精神薬取締法において麻薬として規制されている。医療用麻薬として疼痛管理に使用される場合は、麻薬施用者の免許のもとで施用される。

## [F064] 毒性学総論 ／ D-3-a

**問題**：GHS（化学品の分類及び表示に関する世界調和システム）及びSDS（安全データシート）に関する記述のうち、正しいのはどれか。1つ選べ。

  1. GHSは法的拘束力のある国際条約であり、すべての国に直接適用される
  2. SDSには化学物質の取り扱い上の注意事項のみが記載される
  3. GHSの絵表示（ピクトグラム）は各国が独自にデザインする
◯ 4. SDSは対象化学物質を含む製品を他の事業者に譲渡・提供する際に交付が義務づけられている
  5. GHSでは健康有害性の分類は設けられていない

**正答**：4

**解説**：
1：誤。GHSは国連が策定した分類・表示の世界調和システムであり、それ自体は法的拘束力を持たない。各国がGHSに基づいて国内法を整備することで法的効力を持つ。
2：誤。SDSは16項目からなり、化学物質の特定情報、危険有害性、組成・成分、応急措置、火災時の措置、物理化学的性質、安定性・反応性、毒性情報、環境影響、廃棄上の注意、輸送上の注意等が記載される。取り扱い上の注意事項のみではない。
3：誤。GHSの絵表示（ピクトグラム）は国際的に統一されたデザイン（赤い菱形の枠にシンボル）が定められている。各国が独自にデザインするものではない。
4：正。わが国では、労働安全衛生法及び化管法（PRTR法）に基づき、SDS対象物質を含む製品を他の事業者に譲渡又は提供する際にSDSの交付が義務づけられている。
5：誤。GHSでは、物理化学的危険性、健康有害性、環境有害性の3つの大分類が設けられており、健康有害性には急性毒性、皮膚腐食性、発がん性、生殖毒性等の分類がある。

## [F091] 毒性学総論 ／ D-3-a

**問題**：リスクコミュニケーションに関する記述のうち、正しいのはどれか。1つ選べ。

  1. リスクコミュニケーションとは、専門家が一般市民にリスク情報を一方的に伝達することをいう
  2. リスクコミュニケーションは行政機関のみが実施するものであり、企業や市民は関与しない
◯ 3. リスクコミュニケーションでは、リスクに関する情報をステークホルダー間で双方向に交換し、相互理解を図ることが重要である
  4. リスクコミュニケーションの目的は、リスクがゼロであることを市民に保証することである
  5. リスクコミュニケーションにおいて、科学的な不確実性に関する情報は市民に伝えるべきではない

**正答**：3

**解説**：
1：誤。リスクコミュニケーションは専門家から市民への一方的な情報伝達ではなく、行政、事業者、市民、専門家等の関係者（ステークホルダー）間での双方向の情報交換と対話のプロセスである。
2：誤。リスクコミュニケーションには行政機関だけでなく、事業者（企業）、消費者・市民、学術専門家、メディア等のすべてのステークホルダーが参加することが重要である。
3：正。リスクコミュニケーションとは、リスクの性質、大きさ、管理方法等に関する情報をステークホルダー間で双方向に交換し、相互理解を深めるプロセスである。一方的な情報提供ではなく、関係者間の対話と信頼構築が本質である。
4：誤。あらゆるリスクをゼロにすること（ゼロリスク）は科学的に不可能である。リスクコミュニケーションの目的は、リスクに関する正確な情報を共有し、合理的な意思決定を支援することである。
5：誤。科学的な不確実性が存在する場合、その不確実性の内容と程度を正直に伝えることがリスクコミュニケーションにおいて重要である。不確実性を隠すことは信頼関係を損なう。

## [F095] 毒性学総論 ／ D-3-a

**問題**：予防原則（precautionary principle）に関する記述のうち、正しいのはどれか。2つ選べ。

  1. 予防原則は、科学的にリスクが完全に否定された場合にのみ適用される
◯ 2. 予防原則では、科学的な不確実性が存在する場合でも、深刻かつ不可逆的な被害のおそれがあれば予防的措置を講じることが求められる
  3. 予防原則は1992年のリオ宣言には含まれていない
  4. 予防原則の適用には完全な科学的因果関係の証明が前提条件となる
◯ 5. 予防原則はEU（欧州連合）の化学物質規制政策の基本理念の一つとなっている
