# D-1-c / 毒性学総論
（5問）

## [F437] 毒性学総論 ／ D-1-c

**問題**：アフラトキシンに関する記述のうち、正しいのはどれか。1つ選べ。

  1. アフラトキシンはFusarium属のカビが産生する
  2. わが国ではアフラトキシンの規制基準は設定されていない
  3. アフラトキシンは加熱調理で容易に分解される
◯ 4. アフラトキシンB₁は最も強い発がん性を示すカビ毒の一つである
  5. アフラトキシンの主な標的臓器は腎臓である

**正答**：4

**解説**：
1：誤。アフラトキシンはAspergillus flavusやA. parasiticusなどのAspergillus属のカビが産生する。Fusarium属ではない。
2：誤。わが国では食品衛生法に基づきアフラトキシンの規制基準が設定されている。
3：誤。アフラトキシンは耐熱性が高く、通常の加熱調理（100℃程度）では完全には分解されない。
4：正。アフラトキシンB₁はIARCの発がん性評価でグループ1（ヒトに対する発がん性が認められる）に分類され、最も強い発がん性を示すカビ毒の一つである。
5：誤。アフラトキシンの主な標的臓器は肝臓であり、肝細胞がんを引き起こす。腎臓ではない。

## [F439] 毒性学総論 ／ D-1-c

**問題**：食品中の発がん物質に関する記述のうち、正しいのはどれか。1つ選べ。

◯ 1. ヘテロサイクリックアミン（HCA）は焦げた肉や魚に含まれる発がん物質である
  2. ベンゾ[a]ピレンはメイラード反応により生成する
  3. N-ニトロソジメチルアミン（NDMA）はビタミンCの酸化により生成する
  4. アクリルアミドは油脂の自動酸化の最終産物である
  5. ダイオキシン類は食品添加物として使用されている

**正答**：1

**解説**：
1：正。ヘテロサイクリックアミン（HCA）はアミノ酸やクレアチンが高温加熱されることで生成する発がん物質であり、焦げた肉や魚に含まれる。Trp-P-1, Trp-P-2, IQなどがある。
2：誤。ベンゾ[a]ピレンは不完全燃焼により生成する多環芳香族炭化水素（PAH）であり、メイラード反応産物ではない。くん煙食品や焼き魚等に含まれる。
3：誤。NDMAはジメチルアミンと亜硝酸（硝酸塩由来）が反応して生成するニトロソアミンである。ビタミンC（アスコルビン酸）はむしろニトロソ化を阻害する。
4：誤。アクリルアミドはアスパラギンと還元糖によるメイラード反応の産物である。油脂の自動酸化とは異なる。
5：誤。ダイオキシン類は環境汚染物質であり、食品添加物ではない。廃棄物の焼却等で発生し、食物連鎖を通じて食品を汚染する。

## [F441] 毒性学総論 ／ D-1-c

**問題**：食品中の発がん物質のうち、IARCの発がん性評価でグループ1（ヒトに対する発がん性が認められる）に分類されるのはどれか。1つ選べ。

  1. アクリルアミド
  2. フラン
◯ 3. アフラトキシン
  4. Trp-P-1
  5. スチレン

**正答**：3

**解説**：
1：誤。アクリルアミドはIARCグループ2A（ヒトに対する発がん性がおそらくある）に分類される。
2：誤。フランはIARCグループ2B（ヒトに対する発がん性が疑われる）に分類される。
3：正。アフラトキシンはIARCグループ1（ヒトに対する発がん性が認められる）に分類される。
4：誤。Trp-P-1はIARCグループ2B に分類される。
5：誤。スチレンはIARCグループ2B に分類される。

## [F443] 毒性学総論 ／ D-1-c

**問題**：食品中のN-ニトロソアミンに関する記述のうち、正しいのはどれか。1つ選べ。

  1. N-ニトロソアミンは発がん性を示さない
  2. 加熱食品にのみ含まれ、生食品には含まれない
  3. アスコルビン酸（ビタミンC）はニトロソ化を促進する
  4. N-ニトロソアミンは発色剤として食品に添加される
◯ 5. 亜硝酸塩と二級アミンの反応により食品中で生成しうる

**正答**：5

**解説**：
1：誤。N-ニトロソアミン（NDMAなど）は強い発がん性を示す。IARCグループ2Aに分類されるものもある。
2：誤。N-ニトロソアミンは加熱食品だけでなく、塩蔵食品や発酵食品など様々な食品に含まれうる。
3：誤。アスコルビン酸（ビタミンC）やエリソルビン酸はニトロソ化を阻害する作用がある。
4：誤。N-ニトロソアミンは有害物質であり、食品添加物として使用されるものではない。発色剤として使用されるのは亜硝酸ナトリウム等である。
5：正。N-ニトロソアミンは発色剤として使用される亜硝酸塩と食品中の二級アミンが酸性条件下で反応（ニトロソ化反応）することにより生成しうる。

## [F549] 毒性学総論 ／ D-1-c

**問題**：毒性試験に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 慢性毒性試験は28日間の投与期間で行う
  2. 亜急性毒性試験は1年以上の投与期間で行う
◯ 3. 単回投与毒性試験（急性毒性試験）ではLD50を求める
  4. 生殖毒性試験は変異原性を評価する試験である
  5. 遺伝毒性試験では発がん性を直接判定する

**正答**：3

**解説**：
1：誤。慢性毒性試験は通常1年以上（げっ歯類では1年以上）の投与期間で行う。28日間は亜急性毒性試験である。
2：誤。亜急性毒性試験は通常28〜90日間の投与期間で行う。1年以上ではない。
3：正。単回投与毒性試験（急性毒性試験）は被験物質を1回投与してLD50（半数致死量）を求める試験である。
4：誤。生殖毒性試験は生殖・発生に対する影響を評価する試験であり、変異原性の評価ではない。
5：誤。遺伝毒性試験は遺伝子への影響（変異原性）を評価する試験であり、発がん性を直接判定するものではない。
