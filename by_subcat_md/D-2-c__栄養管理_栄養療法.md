## [F230] 栄養管理・栄養療法 ／ D-2-c

**問題**：55歳男性。BMI 27.5、血圧145/92 mmHg、空腹時血糖126 mg/dL。メタボリックシンドロームと診断された。この患者への栄養指導に関する記述のうち、適切なのはどれか。2つ選べ。

  1. エネルギー摂取量を増やし、筋肉量の増加を優先する
◯ 2. 食塩摂取量を1日6 g未満に制限することを推奨する
  3. 脂質エネルギー比率を50%以上にすることを推奨する
◯ 4. 食物繊維の摂取を増やし、食後血糖値の上昇を緩やかにすることを推奨する
  5. カリウムの摂取を制限することを推奨する

**正答**：2、4

**解説**：
1：誤。BMI 27.5は肥満（25以上）であり、エネルギー摂取量を適正化（減少）して体重減量を図ることが優先される。
2：正。高血圧を合併しているため、日本高血圧学会ガイドラインに基づき食塩摂取量を1日6 g未満に制限する。食事摂取基準でも成人男性の目標量は7.5 g/日未満である。
3：誤。脂質エネルギー比率の目標量は20〜30%であり、50%以上は過剰である。特に飽和脂肪酸の摂取制限が重要。
4：正。食物繊維は食後血糖値の急激な上昇を抑制する効果がある。目標量は成人男性21 g/日以上。空腹時血糖126 mg/dLは糖尿病型であり、食物繊維摂取の増加は適切な指導である。
5：誤。カリウムは血圧低下作用があり、高血圧患者では積極的な摂取が推奨される（腎機能正常の場合）。制限が必要なのは腎機能低下患者である。

## [F250] 栄養管理・栄養療法 ／ D-2-c

**問題**：高齢者の栄養障害に関する記述のうち、正しいのはどれか。2つ選べ。

◯ 1. サルコペニアは、加齢に伴う筋肉量の減少と筋力の低下を特徴とする
  2. フレイル（虚弱）は、不可逆的な状態であり改善は期待できない
◯ 3. 高齢者のタンパク質摂取量の低下は、サルコペニアのリスク因子である
  4. 高齢者では、BMIが高いほど死亡リスクが低下する
  5. ロコモティブシンドロームは、栄養過剰のみが原因で生じる

**正答**：1、3

**解説**：
1：正。サルコペニアは加齢に伴う骨格筋量の減少と筋力低下を特徴とする症候群であり、転倒・骨折リスクの増大、ADL低下につながる。
2：誤。フレイルは健常と要介護の中間的な状態であり、適切な介入（栄養改善、運動、社会参加）により健常な状態に戻りうる可逆的な段階である。早期発見・介入が重要である。
3：正。高齢者のタンパク質摂取不足はサルコペニアの主要なリスク因子である。高齢者では若年者より体重あたり多くのタンパク質摂取が推奨される（1.0 g/kg体重/日以上が目安）。
4：誤。高齢者ではBMIと死亡リスクの関係はU字型を示し、BMIが低すぎても高すぎても死亡リスクが上昇する。特にやせ（低栄養）による死亡リスク上昇が問題となる。
5：誤。ロコモティブシンドロームは運動器の障害により移動機能が低下した状態であり、原因は多因子的（骨粗鬆症、変形性関節症、サルコペニアなど）である。栄養過剰のみが原因ではない。

## [F263] 栄養管理・栄養療法 ／ D-2-c

**問題**：経腸栄養剤に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 半消化態栄養剤は、窒素源としてアミノ酸を含有する
  2. 消化態栄養剤は、窒素源としてタンパク質をそのまま含有する
◯ 3. 成分栄養剤（エレンタール等）は、窒素源としてアミノ酸を含有し、脂肪含量が極めて少ない
  4. 経腸栄養剤はすべて食品に分類され、医薬品として扱われることはない
  5. 成分栄養剤は残渣が多く、消化機能が十分な患者にのみ適応される

**正答**：3

**解説**：
1：誤。半消化態栄養剤の窒素源はタンパク質（カゼイン、大豆タンパク等）であり、消化酵素による分解が必要である。アミノ酸を窒素源とするのは成分栄養剤である。
2：誤。消化態栄養剤の窒素源はペプチド（ジ・トリペプチド）であり、タンパク質そのままではない。タンパク質をそのまま含むのは半消化態栄養剤である。
3：正。成分栄養剤（エレンタール配合内用剤等）は窒素源としてアミノ酸のみを含有し、脂肪含量が極めて少ない（約1〜2%）。消化をほとんど必要とせず、クローン病の栄養療法等に用いられる。
4：誤。経腸栄養剤には医薬品に分類されるもの（エレンタール、エンシュア等）と食品に分類されるもの（各種濃厚流動食）がある。
5：誤。成分栄養剤はほぼ無残渣であることが特徴であり、消化機能が低下した患者にも使用できる。

## [F264] 栄養管理・栄養療法 ／ D-2-c

**問題**：中心静脈栄養法（TPN）に関する記述のうち、正しいのはどれか。1つ選べ。

  1. TPNでは、末梢静脈から高カロリー輸液を投与する
◯ 2. 高カロリー輸液にはビタミンB1を添加する必要があり、欠乏すると重篤な乳酸アシドーシスを生じうる
  3. TPNではカテーテル関連血流感染症（CRBSI）のリスクはない
  4. 脂肪乳剤は中心静脈カテーテルからのみ投与可能であり、末梢静脈からは投与できない
  5. NPC/N比（非タンパク質カロリー/窒素比）は低いほど窒素利用効率が高い

**正答**：2

**解説**：
1：誤。TPNは上大静脈等の中心静脈にカテーテルを留置して高カロリー輸液を投与する方法である。末梢静脈から高濃度糖液を投与すると血管炎・血栓性静脈炎を生じる。
2：正。高カロリー輸液では大量のブドウ糖が投与されるため、ビタミンB1（チアミン）の需要が増大する。B1を添加しないとピルビン酸の代謝が障害され、重篤な乳酸アシドーシスやWernicke脳症を生じうる。
3：誤。TPNでは中心静脈カテーテルを長期留置するため、カテーテル関連血流感染症（CRBSI）は重要な合併症である。無菌操作の徹底が不可欠である。
4：誤。脂肪乳剤（イントラリポス等）は等張性であるため、末梢静脈からも投与可能である。必須脂肪酸の補給および静脈炎予防にも有用である。
5：誤。NPC/N比は適正範囲（一般的に150〜200）で窒素利用効率が最も高い。低すぎるとアミノ酸がエネルギー源として消費され、窒素保持効率が低下する。

## [F265] 栄養管理・栄養療法 ／ D-2-c

**問題**：下表は主要疾患の栄養管理ポイントを示している。（A）〜（D）に当てはまるものの正しい組合せはどれか。1つ選べ。

  1. A：制限　B：十分に確保（30-35 kcal/kg/日）　C：増量（1.0-1.2 g/kg/日）　D：食塩・水分制限
  2. A：適正〜やや多め　B：制限　C：制限（0.6 g/kg/日）　D：高タンパク食
  3. A：適正〜やや多め　B：十分に確保（30-35 kcal/kg/日）　C：制限（0.6 g/kg/日）　D：食塩・水分制限
◯ 4. A：適正〜やや多め　B：十分に確保（30-35 kcal/kg/日）　C：増量（1.0-1.2 g/kg/日）　D：食塩・水分制限

**解説**：
1：誤。糖尿病ではタンパク質は制限せず適正〜やや多めとする（腎症合併がない場合）。

## [F266] 栄養管理・栄養療法 ／ D-2-c

**問題**：糖尿病の食事療法に関する記述のうち、正しいのはどれか。2つ選べ。

◯ 1. 適正なエネルギー摂取量は、標準体重×身体活動量で算出する
  2. 糖質を完全に除去する食事が推奨される
◯ 3. 食物繊維の積極的な摂取が推奨される
  4. 飽和脂肪酸の摂取割合に制限はない
  5. アルコールは血糖コントロールに影響しないため制限不要である

**正答**：1、3

**解説**：
1：正。糖尿病の適正エネルギー摂取量は、標準体重（kg）×身体活動量（軽労作25〜30、普通の労作30〜35 kcal/kg/日）で算出する。標準体重は身長(m)²×22で求める。
2：誤。糖質を完全に除去する極端な糖質制限食は推奨されていない。炭水化物エネルギー比50〜60%を目安とし、食後血糖の急激な上昇を避ける工夫が重要である。
3：正。食物繊維（特に水溶性食物繊維）は食後血糖上昇を緩やかにする効果があり、1日20 g以上の摂取が推奨される。野菜を先に食べる「ベジファースト」も有効である。
4：誤。飽和脂肪酸の摂取は7%エネルギー以下を目標とする。動脈硬化性疾患のリスク低減のため脂質の質にも注意が必要である。
5：誤。アルコールは低血糖のリスクや中性脂肪の上昇、体重増加を招くため、原則として制限が推奨される。

## [F267] 栄養管理・栄養療法 ／ D-2-c

**問題**：慢性腎臓病（CKD）の栄養管理に関する記述のうち、誤っているのはどれか。1つ選べ。

  1. CKD保存期では、タンパク質摂取を制限し腎臓への負荷を軽減する
  2. タンパク質制限下では、エネルギー不足にならないよう十分なエネルギー摂取が重要である
  3. CKDステージが進行するほど、カリウムの摂取制限が必要となる
◯ 4. 透析導入後は、透析によるアミノ酸損失を考慮してタンパク質摂取を制限する
  5. CKD患者では食塩摂取を6 g/日未満に制限する

**正答**：4

**解説**：
1：正。CKD保存期（透析前）ではタンパク質摂取を0.6〜0.8 g/kg標準体重/日に制限し、尿素窒素等の老廃物産生を減らして腎機能の悪化を遅延させる。
2：正。タンパク質制限下でエネルギーが不足すると体タンパク質が異化（分解）され、かえって尿素窒素の産生が増加する。十分なエネルギー確保（30〜35 kcal/kg/日）が重要である。
3：正。CKDが進行すると腎臓からのカリウム排泄能が低下し、高カリウム血症のリスクが増大する。野菜・果物の水さらし・茹でこぼし等の調理の工夫が必要である。
4：誤。透析導入後はタンパク質を「制限」ではなく「増量」する。血液透析ではアミノ酸やタンパク質が透析液中に漏出するため、1.0〜1.2 g/kg標準体重/日の摂取が推奨される。
5：正。CKD患者では高血圧の管理と浮腫の予防のため、食塩摂取を3〜6 g/日に制限する。

## [F268] 栄養管理・栄養療法 ／ D-2-c

**問題**：肝硬変の栄養管理に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 肝硬変非代償期では、高タンパク食が推奨される
◯ 2. 肝性脳症の予防・治療には、分岐鎖アミノ酸（BCAA）製剤が用いられる
  3. Fischer比（BCAA/AAA比）は肝硬変で上昇する
  4. 就寝前軽食（LES：late evening snack）は、肝硬変患者では禁忌である
  5. 肝硬変患者ではナトリウムの摂取制限は不要である

**正答**：2

**解説**：
1：誤。肝硬変非代償期（肝性脳症のリスクがある場合）では高タンパク食は禁忌である。タンパク質の過剰摂取はアンモニア産生を増加させ肝性脳症を誘発する。
2：正。肝硬変ではFischer比（BCAA/AAA比）が低下し、芳香族アミノ酸（AAA：フェニルアラニン、チロシン等）が相対的に増加して偽性神経伝達物質の産生につながる。BCAA製剤（リーバクト等）はFischer比を改善し、肝性脳症の予防・治療に用いられる。
3：誤。Fischer比は肝硬変で低下する。BCAAは主に筋肉で代謝されるため肝障害の影響を受けにくいが、AAAは肝臓で代謝されるため肝障害時に血中濃度が上昇する。
4：誤。LES（就寝前軽食：200 kcal程度の炭水化物中心の軽食）は、肝硬変患者の夜間飢餓状態を防ぎ、タンパク質異化を抑制するために推奨される。
5：誤。肝硬変非代償期では腹水・浮腫の管理のためにナトリウム制限（5〜7 g/日）および水分制限が必要である。

**問題**：栄養アセスメントに用いる指標に関する記述のうち、正しいのはどれか。1つ選べ。
