# D-3-e / 産業保健
（5問）

## [F861] 産業保健 ／ D-3-e

**問題**：特殊健康診断に関する記述のうち正しいのはどれか。1つ選べ。

◯ 1. 有害業務従事者を対象として実施される
  2. すべての労働者に義務
  3. 任意で法的義務なし
  4. 生物学的モニタリングは行わない
  5. 10年に1回

**正答**：1

**解説**：
1：正。有機溶剤、特定化学物質、鉛、電離放射線等の有害業務従事者を対象に労働安全衛生法に基づき実施。生物学的モニタリングを含む。
2：誤。全労働者に義務なのは一般健康診断。特殊健康診断は有害業務従事者対象。
3：誤。法的義務。
4：誤。生物学的モニタリングは重要な検査項目。
5：誤。通常6か月に1回。

## [F862] 産業保健 ／ D-3-e

**問題**：トルエンの生物学的モニタリング指標はどれか。1つ選べ。

  1. 血中鉛
◯ 2. 尿中馬尿酸
  3. 尿中δ-ALA
  4. 血中カドミウム
  5. 尿中マンデル酸

**正答**：2

**解説**：
1：誤。血中鉛は鉛曝露の指標。
2：正。トルエンは体内で酸化→安息香酸→グリシン抱合で馬尿酸として尿中排泄。尿中馬尿酸がトルエン曝露の指標。
3：誤。尿中δ-ALAは鉛曝露の指標。
4：誤。血中カドミウムはカドミウム曝露の指標。
5：誤。尿中マンデル酸はスチレン曝露の指標。

## [F864] 産業保健 ／ D-3-e

**問題**：振動障害に関する記述のうち正しいのはどれか。1つ選べ。

  1. 振動障害は振動工具の使用を中止すれば速やかに完全治癒する
  2. 振動障害は騒音暴露が主原因であり聴力障害として現れる
  3. 振動障害はホルムアルデヒド等の化学的要因により発症する疾患である
◯ 4. 振動工具の長期使用によりレイノー現象等を呈する職業性疾患である
  5. 振動工具の使用時間制限は法令上定められていない

**正答**：4

**解説**：
1：誤。振動障害は使用中止後も症状が持続することが多く、完全治癒は困難な場合がある。
2：誤。振動障害は局所振動暴露が原因であり、騒音による聴力障害（騒音性難聴）とは異なる。
3：誤。振動障害は物理的要因（振動）による職業性疾患であり、化学的要因によるものではない。
4：正。振動障害はチェーンソー等の振動工具の長期使用により末梢循環障害（レイノー現象）、末梢神経障害、運動機能障害等を呈する職業性疾患である。
5：誤。チェーンソー等の振動工具については1日の使用時間制限等が通達で定められている。

## [F867] 産業保健 ／ D-3-e

**問題**：メンタルヘルス対策の4つのケアに含まれないのはどれか。1つ選べ。

  1. セルフケア
◯ 2. 患者による診断ケア
  3. 事業場内産業保健スタッフ等によるケア
  4. ラインによるケア
  5. 事業場外資源によるケア

**正答**：2

**解説**：
1：含まれる。労働者自身によるストレスへの気づきと対処。
2：正（含まれない）。「患者による診断ケア」は4つのケアに含まれない。4つのケアはセルフケア、ラインによるケア、事業場内産業保健スタッフ等によるケア、事業場外資源によるケアの4つ。
3：含まれる。産業医・衛生管理者等によるケア。
4：含まれる。管理監督者による部下への配慮。
5：含まれる。専門機関・EAP等による支援。

## [F868] 産業保健 ／ D-3-e

**問題**：熱射病（重症型熱中症）に関する記述のうち正しいのはどれか。1つ選べ。

  1. すべて軽症で入院不要
◯ 2. 体温調節破綻で40℃以上の高体温と意識障害を呈する
  3. WBGTは予防に不使用
  4. 冬季のみ発生
  5. 熱けいれんでは40℃以上になる

**正答**：2

**解説**：
1：誤。重症で死亡リスクあり。
2：正。熱射病は体温調節破綻により発汗停止、40℃以上の高体温、意識障害を呈する最重症型。死亡率が高く緊急冷却が必要。重症度III度に該当。
3：誤。WBGTは熱中症予防の最重要環境指標。
4：誤。主に高温環境で発生。室内でも起こる。
5：誤。熱けいれんは塩分喪失による筋痙攣で体温は正常〜軽度上昇。
