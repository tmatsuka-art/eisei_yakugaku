## [F120] 水環境 ／ D-3-e

**問題**：水質汚濁の指標に関する記述のうち、正しいのはどれか。1つ選べ。

  1. BOD（生物化学的酸素要求量）は、海域や湖沼の水質基準に用いられる。
◯ 2. COD（化学的酸素要求量）の測定には、JIS法では過マンガン酸カリウムが酸化剤として用いられる。
  3. DO（溶存酸素量）が高いほど、水質は悪化していることを示す。
  4. 全窒素・全リンの環境基準は、河川に対して設定されている。
  5. n-ヘキサン抽出物質は、水中の揮発性有機化合物の指標である。

**正答**：2

**解説**：
1：誤。BODは河川の水質基準に用いられる。海域や湖沼の水質基準にはCODが用いられる。河川は流れがあり好気的条件が保たれやすいためBOD、湖沼・海域は閉鎖性水域であるためCODが適する。
2：正。日本のJIS法によるCOD測定では、酸化剤として過マンガン酸カリウム（KMnO₄）が用いられる（CODMn法）。なお、米国等ではニクロム酸カリウム（K₂Cr₂O₇）を用いるCODCr法が採用されている。
3：誤。DO（溶存酸素量）は水中に溶解している酸素の量であり、DOが高いほど水質は良好であることを示す。有機汚濁が進行するとDOは低下する。
4：誤。全窒素・全リンの環境基準は、富栄養化が問題となる湖沼および海域に対して設定されている。河川ではない。
5：誤。n-ヘキサン抽出物質は、水中の油脂類（鉱物油、動植物油脂）の指標である。揮発性有機化合物の指標ではない。

## [F166] 水環境 ／ D-3-e

**問題**：水質汚濁に関する記述のうち、誤っているのはどれか。1つ選べ。

  1. BODは水中の有機物を微生物が分解するのに必要な酸素量である
◯ 2. CODは河川の水質指標として環境基準に用いられている
  3. 水質汚濁防止法では、特定施設からの排水に排水基準が設定されている
  4. 生活排水は水質汚濁の主要な原因の一つである
  5. DO（溶存酸素量）が高いほど水質は良好である

**正答**：2

**解説**：
1：正。BOD（生物化学的酸素要求量）は、水中の有機物を好気性微生物が20℃、5日間で分解する際に消費する酸素量で表される。
2：誤。COD（化学的酸素要求量）は湖沼・海域の環境基準に用いられる。河川の環境基準にはBODが用いられる。これは頻出の区別である。
3：正。水質汚濁防止法では、特定施設を設置する工場・事業場からの排水について、健康項目（有害物質）と生活環境項目の排水基準が定められている。
4：正。生活排水（台所、洗濯、風呂等からの排水）は、水質汚濁の原因の約7割を占めるとされる。
5：正。DO（溶存酸素量）は水中に溶けている酸素の量であり、値が高いほど水質が良好であることを示す。有機物汚濁が進むとDOは低下する。

## [F168] 水環境 ／ D-3-e

**問題**：表は水質汚濁に関する指標をまとめたものである。（A）〜（D）に入る語句の正しい組合せはどれか。1つ選べ。

  1. A：COD　B：BOD　C：微生物による分解量　D：汚濁した水では高値を示す
◯ 2. A：BOD　B：COD　C：過マンガン酸カリウム等による酸化量　D：清浄な水では高値を示す
  3. A：BOD　B：COD　C：微生物による分解量　D：汚濁した水では高値を示す
  4. A：COD　B：BOD　C：過マンガン酸カリウム等による酸化量　D：清浄な水では高値を示す
  5. A：DO　 B：BOD　C：過マンガン酸カリウム等による酸化量　D：清浄な水では高値を示す

**正答**：2

**解説**：
1：誤。AとBが逆転している。BODが溶存酸素消費量、CODが化学的酸化量である。
2：正。BOD（生物化学的酸素要求量）は微生物分解性の有機物量を測定し、COD（化学的酸素要求量）は過マンガン酸カリウムや重クロム酸カリウム等の酸化剤による酸化量を測定する。DOは清浄な水ほど高値を示す。
3：誤。Cの「微生物による分解量」はBODの特徴であり、CODの測定項目ではない。
4：誤。AとBが逆転している。
5：誤。Aは溶存酸素消費量の測定なのでBODである。DOではない。

## [F791] 水環境 ／ D-3-e

**問題**：水道水の遊離残留塩素の下限基準値はどれか。1つ選べ。

  1. 0.01 mg/L
  2. 5.0 mg/L
  3. 1.0 mg/L
◯ 4. 0.1 mg/L
  5. 10.0 mg/L

**正答**：4

**解説**：
1：誤。0.01は基準値より低い。
2：誤。5.0は基準値より高い。
3：誤。1.0は基準値より高い。
4：正。水道法施行規則により給水栓での遊離残留塩素は0.1 mg/L以上を維持することが定められている。
5：誤。10.0は基準値より高い。

## [F877] 水環境 ／ D-3-e

**問題**：下水の高度処理（三次処理）の主な目的はどれか。1つ選べ。

◯ 1. 窒素・リンの除去による富栄養化防止
  2. 一次処理の別名
  3. 有機物除去のみ
  4. 活性汚泥法と同義
  5. 日本では未実施

**正答**：1

**解説**：
1：正。高度処理は二次処理で除去しきれない窒素・リンを除去。閉鎖性水域の富栄養化防止に寄与。A2O法等が用いられる。
2：誤。一次処理は沈殿等の物理処理。
3：誤。主目的は窒素・リン除去。
4：誤。活性汚泥法は二次処理。
5：誤。日本でも実施されている。

## [F882] 水環境 ／ D-3-e

**問題**：クリプトスポリジウムに関する記述のうち正しいのはどれか。1つ選べ。

  1. クリプトスポリジウムはグラム陽性桿菌に分類される細菌の一種である
  2. クリプトスポリジウムのオーシストは次亜塩素酸ナトリウムにより容易に不活化される
  3. クリプトスポリジウムは水系感染とは無関係であり経気道感染が主要な経路である
◯ 4. オーシストは塩素消毒に耐性を示すため浄水処理ではろ過や紫外線照射等の対策が重要である
  5. クリプトスポリジウムによる集団感染は日本国内では報告されたことがない

**正答**：4

**解説**：
1：誤。クリプトスポリジウムは原虫（アピコンプレクサ門の寄生性原虫）であり、細菌ではない。
2：誤。クリプトスポリジウムのオーシストは塩素消毒（次亜塩素酸）に高い耐性を示し、通常の塩素処理では不活化が困難である。
3：誤。クリプトスポリジウムは水系感染（汚染された飲料水の摂取）が主要な感染経路であり、経気道感染ではない。
4：正。クリプトスポリジウムのオーシストは塩素消毒に耐性を示すため、浄水処理では急速ろ過、緩速ろ過、膜ろ過、紫外線照射等による除去・不活化が重要である。
5：誤。1996年の埼玉県越生町の事例をはじめ、日本国内でも水道水を介した集団感染が報告されている。

## [F1105] 水環境 ／ D-3-e

**問題**：水質汚濁の指標に関する記述のうち、正しいのはどれか。2つ選べ。

◯ 1. BOD（生物化学的酸素要求量）は、微生物による有機物の酸化分解に必要な酸素量で表される。
◯ 2. COD（化学的酸素要求量）は、過マンガン酸カリウム（CODMn）や重クロム酸カリウム（CODCr）を用いて測定される。
  3. DO（溶存酸素量）が高いほど、水質は悪化していることを示す。
  4. SS（浮遊物質量）は、水中に溶解している物質の量を示す。
  5. 全窒素・全リンは、水域の栄養塩類の指標であり、値が高いと貧栄養状態を示す。

**正答**：1、2

**解説**：
水質汚濁の各指標の意味と測定法を正確に理解することが重要です。
1:正　BOD（Biochemical Oxygen Demand）は、水中の有機物が微生物により好気的に分解される際に消費される酸素量（mg/L）です。通常20℃で5日間培養して測定します（BOD₅）。
2:正　COD（Chemical Oxygen Demand）は、水中の有機物を化学的酸化剤で酸化する際に消費される酸素量です。日本ではCODMn（過マンガン酸カリウム法）が主に用いられ、海外ではCODCr（重クロム酸カリウム法）も用いられます。
3:誤　DO（Dissolved Oxygen）が高いほど水中に酸素が多く含まれていることを示し、一般に水質が良好であることを意味します。DO低下は有機物汚染の進行を示唆します。
4:誤　SS（Suspended Solids、浮遊物質量）は、水中に浮遊している不溶性の物質の量を示します。溶解している物質ではなく、懸濁している粒子状物質です。
5:誤　全窒素・全リンは水域の栄養塩類（富栄養化）の指標であり、値が高いと富栄養状態を示します。貧栄養状態ではなく、アオコや赤潮の発生リスクが高まります。

## [F1177] 水環境 ／ D-3-e

**問題**：水環境の富栄養化に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 富栄養化の主な原因物質は、重金属とダイオキシン類である。
  2. 閉鎖性水域の富栄養化指標として、CODの環境基準が設定されている。
  3. 赤潮は、淡水域でのみ発生する現象である。
  4. 窒素及びリンに係る環境基準は、全ての公共用水域に適用される。
◯ 5. アオコは、藍藻類（シアノバクテリア）が異常増殖して水面に集積する現象である。

**正答**：5

**解説**：
水環境の富栄養化に関する問題です。
1:誤　富栄養化の主な原因物質は窒素（N）とリン（P）です。重金属やダイオキシン類は水質汚染物質ですが、富栄養化の原因ではありません。
2:誤　CODは有機汚濁の指標です。富栄養化の指標としては全窒素（T-N）と全リン（T-P）の環境基準が設定されています。
3:誤　赤潮は海域（内湾など）で主に発生する現象です。淡水域では赤潮ではなくアオコが問題となります。
4:誤　窒素・リンの環境基準は、湖沼と海域（閉鎖性水域）に適用され、河川には設定されていません。河川は流水であり自浄作用が働くためです。
5:正　アオコ（水の華）は、Microcystisなどの藍藻類（シアノバクテリア）が富栄養化した湖沼で異常増殖し、水面にスカム状に集積する現象です。肝毒素ミクロシスチンを産生する種もあります。
