# D-3-e / 室内環境
（7問）

## [F558] 室内環境 ／ D-3-e

**問題**：ホルムアルデヒドに関する記述のうち、正しいのはどれか。1つ選べ。

◯ 1. ホルムアルデヒドはシックハウス症候群の原因物質の一つである
  2. ホルムアルデヒドはIARCの発がん性分類でGroup 2B（発がん性の可能性あり）に分類されている
  3. ホルムアルデヒドの室内濃度指針値は0.5 mg/m³（0.4 ppm）である
  4. ホルムアルデヒドは主に食品添加物として広く使用されている
  5. ホルムアルデヒドはアセトアルデヒドの酸化により生成される

**正答**：1

**解説**：
1：正。ホルムアルデヒドは建材や接着剤から放散され、シックハウス症候群の主要な原因物質の一つである。室内空気汚染物質として厚生労働省の指針値が設定されている。
2：誤。ホルムアルデヒドはIARCによりGroup 1（ヒトに対して発がん性がある）に分類されている。Group 2Bではない。鼻咽頭がん等との関連が認められている。
3：誤。ホルムアルデヒドの室内濃度指針値は0.1 mg/m³（0.08 ppm）である。0.5 mg/m³ではない。
4：誤。ホルムアルデヒドは食品添加物ではなく、合板の接着剤（尿素樹脂等）や殺菌・防腐剤（ホルマリン）として工業的に使用される。
5：誤。ホルムアルデヒドはメタノールの酸化により生成される。アセトアルデヒドの酸化で生成されるのは酢酸である。

## [F688] 室内環境 ／ D-3-e

**問題**：シックハウス症候群に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 室内の換気はシックハウス症候群の予防に無効である
  2. シックハウス症候群の原因物質にホルムアルデヒドは含まれない
  3. シックハウス症候群は室外の大気汚染のみが原因である
◯ 4. シックハウス症候群は建材等から放散される化学物質が原因となる室内環境に関連した健康被害である
  5. 建築基準法にはシックハウス対策の規定がない

**正答**：4

**解説**：
1：誤。換気はシックハウス症候群の予防に非常に有効であり、建築基準法で24時間換気設備の設置が義務化されている。
2：誤。ホルムアルデヒドはシックハウス症候群の最も代表的な原因物質である。室内濃度指針値は0.08 ppm（100 μg/m³）。
3：誤。シックハウス症候群は主に室内の化学物質汚染が原因であり、室外の大気汚染のみが原因ではない。
4：正。シックハウス症候群は建材・家具・接着剤等から放散されるホルムアルデヒド、トルエン等の揮発性有機化合物（VOC）が原因となる。頭痛、めまい、粘膜刺激等の症状を呈する。
5：誤。建築基準法にはホルムアルデヒドを発散する建材の使用制限や24時間換気設備の設置義務等の規定がある。

## [F689] 室内環境 ／ D-3-e

**問題**：揮発性有機化合物（VOC）に関する記述のうち、正しいのはどれか。1つ選べ。

◯ 1. ホルムアルデヒド・トルエン・キシレン等が代表的なVOCである
  2. VOCは室内環境に関連するがシックハウス症候群とは無関係である
  3. VOCは不揮発性の化学物質の総称である
  4. 室内のVOC濃度に指針値は設定されていない
  5. VOCは大気汚染とは無関係である

**正答**：1

**解説**：
1：正。ホルムアルデヒド、トルエン、キシレン、パラジクロロベンゼン、エチルベンゼン、スチレン等が室内環境で問題となる代表的なVOCであり、それぞれに室内濃度指針値が設定されている。
2：誤。VOCはシックハウス症候群の主要な原因物質群である。
3：誤。VOC（Volatile Organic Compounds）は揮発性の有機化合物の総称である。不揮発性ではない。
4：誤。厚生労働省によりホルムアルデヒド等の個別VOCについて室内濃度指針値が設定されている。
5：誤。VOCは大気中で光化学オキシダントの生成にも関与しており、大気汚染とも関連する。

## [F690] 室内環境 ／ D-3-e

**問題**：室内のCO2（二酸化炭素）濃度に関する記述のうち、正しいのはどれか。1つ選べ。

◯ 1. 室内のCO2濃度は換気の良否の指標として用いられる
  2. CO2は室内環境の汚染指標としては不適切である
  3. 建築物衛生法のCO2基準値は5000 ppm以下である
  4. CO2濃度は室内の温度にのみ影響される
  5. CO2は無毒であるため濃度管理は不要である

**正答**：1

**解説**：
1：正。室内のCO2濃度は換気の良否（適否）を判断する指標として用いられる。建築物衛生法（建築物における衛生的環境の確保に関する法律）では室内のCO2濃度の基準値を1000 ppm以下としている。
2：誤。CO2は在室者の呼吸により発生するため、換気の良否を反映する良い室内環境汚染指標である。
3：誤。建築物衛生法のCO2基準値は1000 ppm以下である。5000 ppmではない。
4：誤。CO2濃度は在室人数、換気量、室容積等に影響される。温度のみではない。
5：誤。CO2は高濃度（3%以上）では頭痛やめまい等の健康影響があり、濃度管理は重要。

## [F697] 室内環境 ／ D-3-e

**問題**：騒音に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 騒音は健康に影響しない物理的刺激である
  2. 騒音は化学的環境要因に分類される
  3. 騒音性難聴は低周波数領域から聴力低下が始まる
  4. 騒音の環境基準は設定されていない
◯ 5. 騒音のレベルはデシベル（dB）で表される

**正答**：5

**解説**：
1：誤。騒音は聴力障害、睡眠障害、心血管系への影響等の健康影響を引き起こす。
2：誤。騒音は物理的環境要因に分類される。化学的環境要因ではない。
3：誤。騒音性難聴は4,000 Hz付近の高周波数領域（c5-dip）から聴力低下が始まるのが特徴的。
4：誤。騒音に係る環境基準は設定されている（地域の類型別に基準値が設定）。
5：正。騒音のレベルは音圧レベルとしてデシベル（dB）で表される。騒音は物理的環境要因の一つであり、聴力障害（騒音性難聴）、睡眠障害、ストレス等の健康影響を引き起こす。

## [F699] 室内環境 ／ D-3-e

**問題**：温熱環境の評価指標に関する記述のうち、正しいのはどれか。1つ選べ。

  1. WBGTはdB（デシベル）で表示される
  2. 不快指数は放射線量を評価する指標である
  3. WBGTは室内環境のVOC濃度を示す
  4. 温熱環境の評価に湿度は考慮しない
◯ 5. WBGT（湿球黒球温度）は熱中症予防のための暑さ指数として用いられる

**正答**：5

**解説**：
1：誤。WBGTは℃で表示される。dBは騒音の単位。
2：誤。不快指数は気温と湿度から算出される温熱環境の快適性指標であり、放射線量の評価指標ではない。
3：誤。WBGTは温熱環境（暑さ）の評価指標であり、VOC濃度とは無関係。
4：誤。温熱環境の評価には気温、湿度、気流、輻射熱の4要素が考慮される。
5：正。WBGT（Wet Bulb Globe Temperature：湿球黒球温度）は気温・湿度・輻射熱を総合的に評価する暑さ指数であり、熱中症の予防に用いられる。環境省により注意喚起の基準が設定されている。

## [F763] 室内環境 ／ D-3-e

**問題**：熱中症予防の指標として用いられるWBGT（湿球黒球温度）の測定に用いる環境因子の組合せとして正しいのはどれか。1つ選べ。

  1. 気温・気圧・風速
◯ 2. 気温・湿度・輻射熱
  3. 照度・騒音・気流
  4. CO₂濃度・湿度・気流
  5. 気温・紫外線・降水量

**正答**：2

**解説**：
1：誤。気圧と風速はWBGTの直接的な測定因子ではない。気圧は高山病等の評価に用いる。
2：正。WBGT（Wet Bulb Globe Temperature）は自然湿球温度（湿度を反映）、黒球温度（輻射熱を反映）、乾球温度（気温）の3つの環境因子から算出する暑さ指数である。屋外ではWBGT=0.7×自然湿球温度+0.2×黒球温度+0.1×乾球温度。
3：誤。照度は視環境、騒音は音環境の指標であり、WBGTには含まれない。
4：誤。CO₂濃度は換気の指標であり、WBGTには含まれない。
5：誤。紫外線や降水量はWBGTの算出に直接用いない。
