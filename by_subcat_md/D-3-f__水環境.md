## [F115] 水環境 ／ D-3-f

**問題**：河川に有機汚濁物質が流入した際の自浄作用について、図は汚水流入点からの距離に応じた水質指標の変化を示している。この図に関する記述のうち、正しいのはどれか。2つ選べ。

◯ 1. BODは汚水流入直後に最も高く、微生物による有機物分解に伴い下流に向かって低下する。
  2. DOは汚水流入点で最も低い値を示す。
◯ 3. NH₄⁺-N濃度は、有機物中の窒素が分解されることにより一時的に上昇する。
  4. NO₃⁻-N濃度の上昇は、嫌気的条件下での脱窒反応を反映している。
  5. 自浄作用が進行しても、BODは元のレベルまで回復しない。

**正答**：1、3

**解説**：
1：正。BOD（生物化学的酸素要求量）は有機汚濁の指標であり、汚水流入直後が最大で、好気性微生物による有機物分解に伴い下流に向かって低下する。
2：誤。DOは汚水流入点では急激には低下せず、流入点よりやや下流の腐敗帯付近で微生物の酸素消費が最大となり、最低値を示す（oxygen sag curve）。
3：正。有機物中の窒素化合物（タンパク質など）が微生物により分解（アンモニア化成）されると、NH₄⁺-Nが生成して一時的に濃度が上昇する。その後、硝化細菌により硝化されNO₃⁻-Nに変換される。
4：誤。NO₃⁻-N濃度の上昇は、好気的条件下での硝化反応（NH₄⁺→NO₂⁻→NO₃⁻）を反映している。脱窒反応は嫌気的条件下でNO₃⁻がN₂に還元される反応であり、NO₃⁻の減少をもたらす。
5：誤。十分な自浄作用が進行すれば、BODは元の清水帯のレベルまで回復する。

## [F162] 水環境 ／ D-3-f

**問題**：湖沼の富栄養化に関する記述のうち、正しいのはどれか。2つ選べ。

◯ 1. 富栄養化の主な原因物質は窒素とリンである
  2. 富栄養化により水中の溶存酸素濃度は上昇する
◯ 3. アオコの原因となる主な微生物は藍藻類（シアノバクテリア）である
  4. 赤潮は淡水湖沼に特有の現象である
  5. 富栄養化した水域ではBOD値が低下する

**正答**：1、3

**解説**：
1：正。窒素とリンの過剰流入が富栄養化の主要原因である。生活排水、農業排水、工場排水が主な供給源となる。
2：誤。富栄養化により藻類が異常増殖し、その後の分解過程で酸素が消費されるため、水中の溶存酸素濃度は低下する。
3：正。アオコ（水の華）はMicrocystis属などの藍藻類（シアノバクテリア）の異常増殖により生じる。一部の藍藻はミクロシスチンなどの肝臓毒を産生する。
4：誤。赤潮は主に海域（内湾）で発生する現象であり、淡水域に特有ではない。淡水域ではアオコが問題となる。
5：誤。富栄養化した水域では有機物が増加するため、BOD値は上昇する。

## [F206] 水環境 ／ D-3-f

**問題**：水道法に基づく水質基準に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 水道水の水質基準は環境基本法に基づいて設定されている
  2. 水道水の残留塩素の基準は、蛇口で0.5 mg/L以上と定められている
◯ 3. 水道水の水質基準項目には、大腸菌、鉛、トリハロメタンなどが含まれる
  4. 水道水の検査は年に1回実施すれば足りる
  5. 水道法は工業用水の水質管理も対象としている

**正答**：3

**解説**：
1：誤。水道水の水質基準は水道法に基づいて厚生労働省令で設定されている。環境基本法に基づくのは公共用水域や地下水の環境基準である。
2：誤。水道法では、給水栓（蛇口）における遊離残留塩素は0.1 mg/L以上を保持することが定められている。0.5 mg/Lではない。
3：正。水道法に基づく水質基準項目（51項目）には、一般細菌、大腸菌、カドミウム、水銀、鉛、ヒ素、六価クロム、総トリハロメタン、塩素酸などが含まれる。
4：誤。水道水の検査項目によって検査頻度は異なるが、毎日の残留塩素検査や月1回以上の項目など、年1回では不十分である。
5：誤。水道法は飲料水の供給（水道事業）を対象としており、工業用水は対象外である。工業用水は工業用水道事業法の対象となる。

## [F219] 水環境 ／ D-3-f

**問題**：ある地域の水道水からPFOS・PFOAが暫定目標値を超えて検出された。薬局薬剤師として住民からの相談を受けた際の対応として、最も適切なのはどれか。1つ選べ。

  1. 「PFASは発がん物質なので、すぐに転居すべきです」と助言する
◯ 2. 「暫定目標値を超えているが、直ちに健康被害が生じる濃度ではないこと」を説明し、行政の対応状況を確認するよう案内する
  3. 「水道水の安全性は保証されているので心配不要です」と断言する
  4. 「専門外なのでお答えできません」と回答する
  5. 「ミネラルウォーターを生涯飲み続けるしかありません」と助言する

**正答**：2

**解説**：
1：誤。PFASの健康影響についてはまだ研究途上であり、IARCではPFOAをグループ2B（ヒトに対する発がん性が疑われる）に分類しているが、直ちに転居を勧めるほどの急性リスクではない。過度な不安を煽る対応は不適切である。
2：正。暫定目標値はリスク管理の指標であり、超過しても直ちに健康被害が生じる濃度とは限らない。科学的根拠に基づいた正確な情報提供を行い、行政（水道事業者、保健所等）の対応状況や代替水源の利用について案内することが適切である。
3：誤。暫定目標値を超えている以上、「安全性が保証されている」と断言することは不正確であり、信頼を損なう。
4：誤。薬剤師は化学物質や健康影響に関する知識を有する専門職であり、住民の健康相談に対応する役割がある。「専門外」として回答を避けることは不適切である。
5：誤。長期的な対策としてボトルウォーターの利用は一つの選択肢であるが、「生涯飲み続けるしかない」は過度な表現であり、行政による水源対策等の展望も含めた説明が必要である。

## [F671] 水環境 ／ D-3-f

**問題**：水道水の残留塩素に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 給水栓での残留塩素濃度の上限は0.4 mg/Lと規定されている
◯ 2. 給水栓での遊離残留塩素は0.1 mg/L以上を維持する必要がある
  3. 結合残留塩素は遊離残留塩素の約10倍の殺菌力を有する
  4. 残留塩素は0.05 mg/L以上あれば一般細菌に対する殺菌効果はない
  5. 水道法により給水栓での残留塩素は0 mg/Lでなければならないと規定されている

**正答**：2

**解説**：
1：誤。残留塩素の上限値は水質管理目標設定項目として1 mg/L以下（おいしい水の要件としてはさらに低い値が望ましい）とされるが、0.4 mg/Lという規定ではない。
2：正。水道法施行規則により、給水栓における水の遊離残留塩素は0.1 mg/L以上（結合残留塩素の場合は0.4 mg/L以上）を保持しなければならない。
3：誤。遊離残留塩素（次亜塩素酸等）は結合残留塩素（クロラミン等）より殺菌力が強い。逆である。
4：誤。残留塩素は適切な濃度であれば水中の病原微生物に対する殺菌効果を有する。
5：誤。水道法では残留塩素の保持が義務づけられており、0 mg/Lにすることは規定されていない。

  2. トリハロメタンには発がん性の懸念はない

  2. BODは海域・湖沼の汚濁指標として用いられる

## [F674] 水環境 ／ D-3-f

## [F693] 水環境 ／ D-3-f

**問題**：水質汚濁に係る環境基準に関する記述のうち、正しいのはどれか。1つ選べ。

◯ 1. 河川の有機汚濁指標にはBODが用いられる
  2. 湖沼の有機汚濁指標にはBODが用いられる
  3. 環境基準は排出基準と同一である
  4. 環境基準は工場の排水にのみ適用される
  5. 環境基準には生活環境項目は含まれない

**正答**：1

**解説**：
1：正。水質汚濁に係る環境基準において、河川の有機汚濁指標にはBODが、湖沼・海域にはCODが用いられる。環境基準には生活環境項目（pH、BOD/COD、DO、SS等）と健康項目（カドミウム、鉛、水銀等の有害物質）がある。

**解説**：

## [F1202] 水環境 ／ D-3-f

  3. 合流式下水道は、雨水と汚水を別々の管渠で集める方式である。
  4. 下水の三次処理（高度処理）は、BODの除去のみを目的とする。

  1. 次亜塩素酸（HClO）の殺菌力は、次亜塩素酸イオン（OCl⁻）よりも弱い。
  2. pHが高いほど、遊離残留塩素に占めるHClOの割合が増加する。
  3. クロラミン類は、遊離残留塩素よりも殺菌力が強いが持続性は低い。
  4. 塩素消毒では、クリプトスポリジウムのオーシストに対しても十分な効果がある。
◯ 5. 塩素消毒の副生成物として、トリハロメタンやハロ酢酸が生成される場合がある。
