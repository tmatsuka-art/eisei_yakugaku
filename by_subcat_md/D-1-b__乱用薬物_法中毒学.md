# D-1-b / 乱用薬物・法中毒学
（11問）

## [F913] 乱用薬物・法中毒学 ／ D-1-b

**問題**：ムレキシド反応で紫紅色を呈する化合物として、正しいのはどれか。1つ選べ。

◯ 1. テオフィリン
  2. モルヒネ
  3. メタンフェタミン
  4. パラコート
  5. メタノール

**正答**：1

**解説**：
1：正。テオフィリンはキサンチン骨格を有する化合物であり、ムレキシド反応で紫紅色を呈する。カフェイン、テオブロミン、尿酸なども同様である。
2：誤。モルヒネの検出にはマルキス試液が用いられ、青藍色を呈する。ムレキシド反応では検出されない。
3：誤。メタンフェタミンの検出にはシモン反応やマルキス試液が用いられる。ムレキシド反応では検出されない。
4：誤。パラコートの検出にはハイドロサルファイトナトリウムによる反応が用いられる。
5：誤。メタノールの検出にはクロモトロプ酸法が用いられ、赤色を呈する。

## [F915] 乱用薬物・法中毒学 ／ D-1-b

**問題**：ドリブンフロー（DRIVEN-FLOW®）に関する記述のうち、誤っているものを1つ選べ。

  1. 尿を試料として用いる
  2. 免疫反応を利用した検査キットである
  3. ベンゾジアゼピン類の検出が可能である
◯ 4. トリカブト由来の自然毒の検出が可能である
  5. ゾルピデムの検出が可能である

**正答**：4

**解説**：
1：正。ドリブンフローは尿を試料として用いる簡易検査キットである。
2：正。免疫反応を利用して乱用薬物の摂取を簡易に判定する。
3：正。ドリブンフローで検出可能な8種類の薬物群にベンゾジアゼピン類（BZD）が含まれる。
4：誤。ドリブンフローはトリカブトなどの自然毒の検出はできない。簡易検査キットは多くの薬毒物の検出ができず、死因判定を目的とする検査としては不十分である。
5：正。ドリブンフローで検出可能な8種類の薬物群にゾルピデム（ZOL）が含まれる。

## [F919] 乱用薬物・法中毒学 ／ D-1-b

**問題**：死後変化（postmortem change）に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 死後拡散では、高濃度のアルコール摂取後に胃内容物が肝右葉に拡散しやすい
  2. モルヒネのグルクロン酸抱合体が死後に分解されてコデインに戻ることがある
  3. 死後産生される化合物はシアン化物イオンに限定される
  4. メタノールやγ-ヒドロキシ酪酸は腐敗細菌によって死後に産生されることはない
◯ 5. ニトロベンゾジアゼピン系薬物は死後に7-アミノ代謝物になることがある

**正答**：5

**解説**：
1：誤。死後拡散では、胃内に残存するアルコールが周囲臓器に拡散し、肝左葉、左肺下葉、左心底部などが汚染されやすい。肝右葉ではなく肝左葉である。
2：誤。モルヒネのグルクロン酸抱合体が死後に分解されてモルヒネに戻ることがある。コデインではなくモルヒネである。
3：誤。死後産生される化合物はシアン化物イオンに限定されず、低級アルコール類、トリプタミン、γ-ヒドロキシ酪酸など多くの化合物が死後に産生されることがある。
4：誤。メタノール、エタノール、n-プロパノール、イソプロパノールのような低級アルコール、トリプタミン、γ-ヒドロキシ酪酸などの低分子化合物は、腐敗細菌によって死後に産生されることがある。
5：正。ニトロベンゾジアゼピン系薬物が死後に7-アミノ代謝物になる例が知られており、これは死後分解（代謝）の一例である。

## [F920] 乱用薬物・法中毒学 ／ D-1-b

**問題**：スタース・オットー（Stas-Otto）法に関する記述のうち、正しいのはどれか。1つ選べ。

  1. もともと無機化合物の抽出法として考案された
  2. 酸性物質は塩基性水溶液に溶けにくい性質を利用している
  3. 揮発性物質の分離に特化した方法である
◯ 4. 現在では生体試料からの分画抽出法の基礎となっている
  5. 単一物質の精製のみに用いられる

**正答**：4

**解説**：
1：誤。スタース・オットー法はもともとアルカロイドの抽出法として考案された。無機化合物の抽出法ではない。
2：誤。酸性物質は酸性水溶液に溶けにくく、塩基性物質は塩基性水溶液に溶けにくい性質を利用している。酸性物質が塩基性水溶液に溶けにくいのではない。
3：誤。スタース・オットー法は難揮発性物質の一般抽出法として利用されるようになった。揮発性物質の分離に特化した方法ではない。
4：正。生体試料からの未知混合物の一斉分析に対して前処理的に用いられる分画抽出法には、スタース・オットー法から発展した方法が多い。
5：誤。スタース・オットー法は未知混合物の一斉分析に対する分画抽出法であり、単一物質の精製のみに用いられるものではない。

## [F921] 乱用薬物・法中毒学 ／ D-1-b

**問題**：シモン（Simon）反応に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 脂肪族一級アミンを検出する反応である
◯ 2. 試薬としてアセトアルデヒドとニトロプルシドナトリウムを用いる
  3. エフェドリンは青〜青藍色を呈する
  4. モルヒネの検出に特異的である
  5. 呈色反応の観察にはグアヤク脂試験紙を用いる

**正答**：2

**解説**：
1：誤。シモン反応はメタンフェタミンなどの脂肪族二級アミンを検出する反応であり、一級アミンではない。
2：正。シモン反応では、20%炭酸ナトリウム溶液、50%アセトアルデヒド-エタノール溶液、1%ニトロプルシドナトリウム溶液を試料に加え、青〜青藍色の呈色を観察する。
3：誤。エフェドリンは二級アミンであるが、シモン反応では例外的に陰性を示す。
4：誤。モルヒネの検出にはマルキス試液を用いる。シモン反応はメタンフェタミン等の脂肪族二級アミンの検出に用いられる。
5：誤。グアヤク脂試験紙はシアンのシェーンバイン-パーゲンステッヘル法で用いるものであり、シモン反応では白色滴板を用いる。

## [F922] 乱用薬物・法中毒学 ／ D-1-b

**問題**：シアンのシェーンバイン-パーゲンステッヘル法に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 試料を水酸化ナトリウム水溶液で塩基性にして加温する
  2. 蒸気をクロモトロプ酸試験紙に触れさせて呈色を観察する
  3. 呈色が赤色であればシアン化物の存在が予測される
◯ 4. 試験紙は硫酸銅水溶液で湿らせたグアヤク脂試験紙を用いる
  5. メタノールの検出にも利用できる

**正答**：4

**解説**：
1：誤。試料を酒石酸酸性にして加温する。水酸化ナトリウムで塩基性にするのではない。
2：誤。蒸気を1%硫酸銅水溶液で湿らせたグアヤク脂試験紙に触れさせる。クロモトロプ酸試験紙ではない。
3：誤。青色の呈色がシアン化物の存在を示す。赤色ではなく青色である。
4：正。グアヤク脂試験紙（ろ紙を10%グアヤク脂溶液に浸し風乾したもの）を1%硫酸銅水溶液で湿らせて使用する。
5：誤。メタノールの検出にはクロモトロプ酸法を用いる。シェーンバイン-パーゲンステッヘル法はシアン化物の検出法である。

## [F923] 乱用薬物・法中毒学 ／ D-1-b

**問題**：メタノールのクロモトロプ酸法に関する記述のうち、誤っているものを1つ選べ。

  1. 過マンガン酸カリウム溶液を加えて酸化する
  2. 亜硫酸ナトリウム溶液を加えて脱色する
  3. クロモトロプ酸溶液を加えた後に加熱する
◯ 4. メタノールが存在すれば青色を呈する
  5. リン酸溶液を使用する

**正答**：4

**解説**：
1：正。試料溶液に5%リン酸溶液および5%過マンガン酸カリウム溶液を加えて酸化する。
2：正。20%亜硫酸ナトリウム溶液を加えて脱色する。
3：正。2%クロモトロプ酸溶液を加え、80〜85°Cの水浴中で10分間加熱する。
4：誤。メタノールが存在すれば赤色を呈する。青色ではなく赤色である。
5：正。5%リン酸溶液を使用する。

## [F929] 乱用薬物・法中毒学 ／ D-1-b

**問題**：死後分解（postmortem metabolism）に関する記述のうち、誤っているものを1つ選べ。

  1. 薬毒物は死後にも活性を維持する加水分解酵素の作用を受けることがある
  2. 腐敗細菌や腸内細菌の作用により薬毒物が酵素学的な変化を受けることがある
  3. 一部のカルバメート系農薬は血中ヘモグロビンと結合し遊離血中濃度が低下する
  4. 死後特有の分解物を定量することにより死後経過時間を推定することが可能である
◯ 5. 死後分解は死後数日経過してから初めて起こり、死後直後には起こらない

**正答**：5

**解説**：
1：正。ご遺体に残存する薬毒物は、死後にも活性を維持し続ける加水分解酵素の作用によって変化を受けることがある。
2：正。腐敗細菌あるいは腸内細菌等の微生物の作用によって、死後直後から経時的に酵素学的な変化を受けることがある。
3：正。一部のカルバメート系の農薬は、血中のヘモグロビンと化学的に結合し、遊離血中濃度が低下することが知られている。
4：正。死後特有の分解物（代謝物）を定量することにより、死後経過時間を推定することも可能である。
5：誤。死後分解は死後直後から経時的に起こるものであり、数日経過してから初めて起こるものではない。

  1. モルヒネ
◯ 2. アンチピリン
  3. コデイン
  4. メタンフェタミン
  5. ヘロイン

**解説**：

2：正。アンチピリンはマルキス試液で黄緑色を呈する。クロロエフェドリンも同様に黄緑色を呈する。
3：誤。コデインはマルキス試液で青藍色を呈する。
4：誤。メタンフェタミンはマルキス試液で赤橙色を呈する。
5：誤。ヘロインはマルキス試液で青藍色を呈する。

## [F936] 乱用薬物・法中毒学 ／ D-1-b

**問題**：死後拡散（postmortem diffusion）に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 死後拡散はアルコール摂取後の遺体でのみ起こる現象である
  2. 胃内に残存するアルコールは肝右葉に拡散しやすい
◯ 3. アミトリプチンやリチウムでも死後拡散が報告されている
  4. 死後拡散によって血中濃度は必ず低下する
  5. 死後拡散は死後1週間以降にのみ観察される

**正答**：3

**解説**：
1：誤。死後拡散はアルコールだけでなく、抗うつ薬のアミトリプチンや気分安定薬のリチウム等でも報告されている。
2：誤。胃内に残存するアルコールが周囲臓器に拡散し、肝左葉、左肺下葉、左心底部などが汚染されやすい。肝右葉ではなく肝左葉である（胃は左側に位置するため）。
3：正。高濃度のアルコール摂取後の死後拡散に加え、抗うつ薬のアミトリプチンや気分安定薬のリチウム等でも同様の現象が報告されている。
4：誤。死後拡散は胃内容物等から周囲臓器への拡散であり、採取部位によっては濃度が上昇することがある。必ず低下するわけではない。
5：誤。死後拡散の時期について1週間以降に限定される記載はない。死後変化は死後直後から起こり得る。

## [F940] 乱用薬物・法中毒学 ／ D-1-b

**問題**：生体中の薬毒物の動態と死後変化に関する記述のうち、正しいのはどれか。1つ選べ。

  1. 生体中では薬毒物はADMEという動態が起こり、遺体でも同様の生命反応が継続する
◯ 2. 死後変化が起こりやすい薬物では、死亡時の濃度と試料採取時の濃度が大きく異なる可能性がある
  3. 死後産生により検出される化合物はエタノールのみである
  4. 遺体から検出された薬物濃度は死亡時の濃度と常に一致する
  5. 検出法が未知の薬物が使用された可能性を考慮する必要はない

**正答**：2

**解説**：
1：誤。生体中ではADME（吸収・分布・代謝・排泄）が起こるが、遺体ではこのような生命反応は起こらない。代わりに死後特有の変化（postmortem change）が起こる。
2：正。死後変化が起こりやすい薬物は、死亡時の濃度と試料採取時の濃度が大きく異なっている可能性があることに留意する必要がある。
3：誤。死後産生される化合物にはエタノールのほかに、メタノール、n-プロパノール、イソプロパノール、トリプタミン、γ-ヒドロキシ酪酸、シアン化物イオンなどがある。
4：誤。死後変化（死後拡散、死後分解、死後産生）により、遺体から検出された薬物濃度は死亡時の濃度と異なることがある。
5：誤。検出法が未知の薬物が使用された可能性も考慮して、血液・尿などを一定期間保管しなければならない。
